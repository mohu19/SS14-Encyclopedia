## 1. 概述

机甲（Mech）是可驾驶的大型外骨骼载具，玩家坐进驾驶舱后通过**动作条**控制机甲移动、切换武器、开灯、开内部循环等。机甲的一切行动依赖**插入的反应堆电池**供电，武器开火直接**扣机甲电量**（星光定制，官方上游是武器自带电池模式）。

本 fork 共 **15 种机甲底盘**（16 个具体实体，含 H.O.N.K. 满配变体），分工业/战斗/特殊/小型四系，由白名单标签（`IndustrialMech`/`CombatMech`/`SpecialMech`/`SmallMech`）约束可安装的设备。星光层对机甲的改动极大：新增气罐槽、推进器、汽笛、夜视、空气喇叭、博格式维修、反应堆电池体系、能量直扣武器、设备径向选择 UI 等，官方上游文件内也遍布 `# Starlight` 内嵌改动。

**中文名（zh-CN locale 官方译名）**：里普利 APLU（MechRipley）、H.O.N.K. 机甲（MechHonker）、HAMTR 机甲（MechHamtr）、Vim 微型机甲（MechVim）、里普利 APLU MK-II（MechRipley2）、帕迪（MechPaddy）、克拉克（MechClarke）、盖吉斯（MechGygax）、杜兰德（MechDurand）、掠夺者（MechMarauder）、炽天使（MechSeraph）、暗黑盖吉斯（MechGygaxSyndie）、虐杀者（MechMaulerSyndie）、暗黑 H.O.N.K.（MechHonkerDark）、缄默（MechMimeSyndie）。

## 3. 驾驶机制

### 3.1 进出机甲

| 操作 | 时长 | 说明 | 来源 |
|---|---|---|---|
| 进入（右键动词或拖拽） | **3 秒** DoAfter（移动打断） | 要求机甲空舱 + 目标可移动 + 通过驾驶者白名单 | MechComponent.cs:160（EntryDelay 3）+ MechSystem.cs:473-478 + SharedMechSystem.cs:682-687 |
| 自行退出（动作条） | 瞬间 | 驾驶者本人随时可退 | MechSystem.cs:491-494（args.User == pilot 直接 TryEject） |
| 把别人拽出 | **3 秒** DoAfter | 大号弹窗警告"正在把 X 拽出" | MechComponent.cs:167（ExitDelay 3）+ MechSystem.cs:497-503 |
| 拆电池 | **2 秒** DoAfter（Prying 工具） | 需线束面板开启 | MechComponent.cs:173（BatteryRemovalDelay 2）+ MechSystem.cs:282-304 |

进入瞬间：**丢光手上所有物品**（`MechSystem.cs:521-523`）、关闭已开 UI（`MechSystem.cs:526`）、机甲加入驾驶者阵营 `_factionSystem.Up`（`MechSystem.cs:529`）；退出时移除阵营成员组件（`MechSystem.cs:540`）。驾驶者获得 `MechPilotComponent` + 交互/移动中继（`SharedMechSystem.cs:250-278`）。

**驾驶者白名单**（pilotWhitelist）：绝大多数机甲要求 `HumanoidAppearance`；HAMTR 要求 `Hamster` 标签（仓鼠）；Vim 要求 `VimPilot` 标签。**机器人/博格**默认不能驾驶，需安装 `MechEquipmentBorgPilot`（外骨骼硅基控制信标，被动设备，`PilotSupportModule` 把 BorgChassis 并入机甲白名单，`PilotSupportModuleSystem.cs:23-43`；拆下时强制弹射驾驶者并移除白名单，`:45-67`）。

### 3.2 驾驶者状态保护（星光）

- **完全绝缘**：驾驶者触电系数 ×0（`SharedMechSystem.cs:713-714`）——机甲被电击不会传导给驾驶者
- **不可击倒**：驾驶中 KnockDownAttempt 被取消（`SharedMechSystem.cs:157-161`）
- **不可躺下**："You can't lie down while piloting a mech."
- 近战判定以机甲为原点/武器（`SharedMechSystem.cs:627-651`），无法攻击自己乘坐的机甲（`:658-662`）
- 驾驶者无法对机甲使用工具（`MechSystem.cs:440-444`）

### 3.3 移动控制

- 移动输入中继到机甲（`SharedMechSystem.cs:260` Mover relay）；全机甲统一走速 2（冲刺各异）
- **0% 电量即停机**（星光改）：显示电量 ≤0%（`(int)(Energy/MaxEnergy*100) == 0`，即 <1%）→ 移动被取消；破损/耐久 ≤0/无电池/维护模式同样禁止移动（`SharedMechSystem.cs:103-119`）
- 机甲可被拉动（Pullable），但**有驾驶者或维护模式下不可被拉**（`SharedMechSystem.cs:133-137`）
- 转向无限制（ChangeDirectionAttemptEvent 星光新增拦截同移动条件）

### 3.5 维护模式（星光重做）

- 通过机甲 UI 开关维护模式，**联动线束面板**开关（`MechSystem.cs:403-432` TryToggleMaintenanceMode → `_wires.TogglePanel`）
- 维护模式下：**不能移动**（§3.3）、**不能开火**（`SharedMechSystem.cs:139-146`）
- 维护模式**必需**操作：安装/拆除设备（`MechEquipmentSystem.cs:43-47`、`MechSystem.cs:390-394`）、维修机甲（`SharedMechSystem.cs:148-155`）
- 线束面板只能由机甲自身切换（`SharedMechSystem.cs:708-711`），防止他人乱动

### 3.6 维修（星光博格式）

焊接工具（`RepairableComponent.cs:46` QualityNeeded=Welding）+ 每次 **1 秒** + **3u 焊接燃料**，修复 **30 耐久**（`mechs.yml:16-21` damageValue -30 / doAfterDelay 1 / fuelCost 3；官方默认 5u）。杜兰德 465 耐久全修约 16 次 ≈ 16 秒 / 48u 燃料（源码注释自述"15 seconds to repair durand"）。

### 3.7 损坏与破坏

- 耐久 = 上限 − 累计伤害（`MechSystem.cs:544-556` OnDamageChanged）；归零 → `BreakMech`：弹射驾驶者、强制清空全部设备、标记 Broken、更新外观（`SharedMechSystem.cs:312-326`）
- 破损机甲不可进入、不可维修（修复需先修复损坏的机械结构？否——维修条件仅是维护模式；破损由 SetIntegrity 在耐久 >0 时自动恢复 Broken=false，`SharedMechSystem.cs:498-506`）
- **伤害传递**：驾驶者在舱内时，新增伤害 × `MechToPilotDamageMultiplier` 同步打给驾驶者（`MechSystem.cs:549-555`）。**星光所有机甲该系数 = 0.0（"Mechs are safe"），唯一例外：里普利 0.75**（mechs.yml:137）——开里普利挨打会连坐
- 电磁卡 emag：清除设备白名单（可装任意设备），并不破坏机甲（`SharedMechSystem.cs:697-704`）

### 3.8 空气与生命维持（星光）

- 所有机甲有 `MechAirComponent`（官方组件，舱内容积 **70L**，`MechAirComponent.cs:13`）；**星光在 MapInit 时把舱内气体填成纯 Frezon 并锁定**（`MechSystem.cs:757-764`，注释是 EVA 梗 "You will get in the LCL and you will like it"）
- 气密机甲（airtight: true）：舱内气体用于暴露判定；非气密机甲呼吸外部空气
- 呼吸逻辑：不开内部循环时吸机甲所在格气体；开内部循环（需插入 `MechAirTank` 气罐）从气罐供气（`MechSystem.cs:706-724`）；呼气始终排向外部（`:726-735`）
- 气罐 `MechAirTank` 容量 100L（`exosuit_components.yml:90-116`）；满配 `MechAirTankFilled` 3000L 含 50 摩尔气体（`gas_tanks.yml:71-82`）

### 4.2 耗电模型（星光重写）

- 机甲能量 = 插入电池的实时电量（`MechSystem.cs:200-243`）；`TryChangeEnergy` 直接操作电池系统扣/充（`MechSystem.cs:615-651`）
- **被动耗电轮询**：每 **0.5 秒**（`MechComponent.cs:29` Delay）查询一次 `GetPassiveChargeDrawRate` 事件累加值并扣电（`MechSystem.cs:124-159`）；推进器开启时贡献 **2/s** 耗电（`MechThrustersComponent.cs:17` DrawRate 2）
- **武器开火直扣机甲能量**：`MechAmmoProvider`（星光组件）按 `fireCost` 从机甲电池扣费出弹，能量不足打不出（`SharedGunSystem.MechAmmo.cs:40-58`）
- 电量读数为 **0% 即停机**（§3.3），非等电池彻底耗尽
- 低电警告：≤**33%** 触发低电音效（星光把阈值提前；`SharedMechSystem.cs:464-478`）；到 0% 播断电音效、自动关灯（`MechSystem.cs:200-209`）
- 灯光耗电：官方遗留 `PowerCellDraw` 组件被禁用（`mechs.yml:101-103`，星光把被动耗电统一移到 MechSystem 轮询），灯光本身不额外扣电（仅需电量 >0）

## 8. 维护要点（分析推导，非源码事实）

1. **电量 = 生命线**：武器 fireCost 直接从机甲电量扣，0% 即瘫。满配掠夺者（Hyper 1800）打脉冲步枪（80/发）理论 22 发续航；炽天使（Antique 1200）开火间隙 60/s 自充，几乎无限火力但重武器（离子 400/发、BRM-6 315/发）仍会瞬间掏空
2. **反应堆可换**：骑兵反应堆（冲刺 ×1.5）装在慢速重机甲（杜兰德/虐杀者）上是质变；圣骑士反应堆自带能量护盾
3. **维护模式双刃剑**：装拆设备/维修必须开维护模式，但开维护模式=不能动不能打（约等于投降）
4. **机甲 vs 电击**：多数机甲电抗系数 >1（怕电），被电击武器/特斯拉类克制；虐杀者例外（0.8 抗电）
5. **别开里普利挨打**：唯一有 0.75 伤害传递的机甲；其余全部 0 传递
6. **维修成本**：焊接 3u/30 耐久，杜兰德满修约 16 秒/48u 燃料——比官方默认（5u/次）便宜且快

## 9. 疑点清单

1. **武器自带电池疑似死代码**：太阳神（240）、离子炮（400）、X 射线（400）、BRM-6（220）自带 BatteryComponent，`MechGunSystem.cs:30-45` 在开火后尝试从机甲能量把电池回满；但弹药已由 MechAmmoProvider 直扣机甲能量，武器电池无任何消耗路径（代码 TODO 注释"机甲电量本应开火时直扣"）——疑似过渡代码，实际不影响战斗
2. **breakOnEmag 名不副实**：`MechComponent.cs:32-36` 注释称"emag 是否禁用机甲"，实际 `OnEmagged` 只清除设备白名单（`SharedMechSystem.cs:697-704`），不破坏不锁机
3. **舱内气体 = Frezon**：`MechSystem.cs:757-764` MapInit 把舱内填纯 Frezon 并 MarkImmutable（EVA 的 LCL 梗）；气密机甲舱内实际是氟利昂而非空气，但 MarkImmutable 防止反应，驾驶者呼吸走气罐或外部空气，不受影响
4. **"15 seconds to repair durand" vs 实测**：注释（mechs.yml:18）说 15 秒，按 465/30 = 15.5 次 × 1s ≈ 15.5 秒（含燃料 46.5u）——基本吻合，但单次是 1s 不是注释暗示的连续 15s
5. **燃尽反应堆无熔化逻辑**：40000 容量 + 无自充，描述声称"使用中熔化"，代码无任何熔毁/过热机制——纯一次性大电池
6. **骑兵反应堆无对应机甲**：全库无 MechCavalier 实体，仅打捞战利品掉落（`salvage_loot_{moderate,challenging}.yml:45-64`）
7. **部分机甲无灯光**：HONK/HAMTR/Vim/暗黑 HONK/掠夺者/炽天使没有 PointLight 组件 → 动作条不给开灯动作（`SharedMechSystem.cs:293-294` 有灯才加动作）
8. **HAMTR/Vim 白名单过窄**：Hamster/VimPilot 标签目前只对应宠物/老鼠类（Vim 描述为站内宠物设计），人类驾驶者进不去
9. **官方层 `PowerCellDraw` 遗留**：`mechs.yml:101-103` enabled:false drawRate 0.3333（注释"星光，3 秒一抽"）——星光把被动耗电统一迁到 MechSystem 0.5s 轮询 + GetPassiveChargeDrawRate 事件，此组件纯遗留
10. **Vim 描述 TODO**：`mechs.yml:328-329` 注释 buzz/chime 动作与内置手电未实现
