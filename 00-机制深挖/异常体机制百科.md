## 一、异常体是什么

异常体（Anomaly）是出现在空间站上的**静态不可移动**实体，会周期性"脉冲"释放效果。每个异常有**三个核心数值**：

| 数值 | 范围 | 说明 | 源码 |
|---|---|---|---|
| 严重性 Severity | 0 ~ 1 | 只增不减（脉冲、粒子、超阈值稳定性增长都会抬升），决定效果强度；**达到 1 触发超临界事件** | `Content.Shared/Anomaly/Components/AnomalyComponent.cs:41-49` |
| 稳定性 Stability | 0 ~ 1 | 双向浮动。> 0.5（GrowthThreshold）= 不稳定，严重性持续增长；< 0.15（DecayThreshold）= 衰减，生命值流失 | `AnomalyComponent.cs:27-37,66,81` |
| 生命值 Health | 0 ~ 1 | 隐藏属性。被**收容粒子**命中减少；归零异常直接消失（无超临界） | `AnomalyComponent.cs:52-59` |

初始值：稳定性随机 (0.4, 0.6)（±0.2 围绕完美平衡 0.5），严重性随机 (0.1, 0.5)（`AnomalyComponent.cs:159,168`）。

接触异常本体受 **10 点辐射伤害**（`anomalies.yml:52-60`，BaseAnomaly 的 DamageOnInteract/DamageOnAttacked）。

## 二、脉冲（Pulse）机制

脉冲是异常体周期性的效果爆发，由 `SharedAnomalySystem.Update` 驱动（`Content.Shared/Anomaly/SharedAnomalySystem.cs:360-404`）。

**脉冲间隔公式**（`SharedAnomalySystem.cs:332-346`）：

```
modifier = clamp((Stability - 0.5) / 0.5, 0, 1)
间隔 = (MaxPulseLength - MinPulseLength) × modifier + MinPulseLength
      再 × 行为脉冲频率修正（PulseFrequencyModifier）
      再 × 随机波动 (1 ± PulseVariation)
```

| 参数 | 默认值 | 说明 | 源码 |
|---|---|---|---|
| MinPulseLength | 2 分钟 | 稳定状态下的最长间隔 | `AnomalyComponent.cs:102` |
| MaxPulseLength | 4 分钟 | 稳定性越高间隔越短（线性压缩） | `AnomalyComponent.cs:108` |
| PulseVariation | ±10% | 每次脉冲间隔的随机波动 | `AnomalyComponent.cs:114` |
| PulseStabilityVariation | (-0.1, 0.15) | 每次脉冲后稳定性变化量 × 当前严重性；**偏向上涨**（注释：because that's funny） | `AnomalyComponent.cs:123` |
| ⚡ 首次脉冲延迟 | 间隔 × 3 | 星光改动：出生后第一次脉冲明显更晚 | `Content.Server/Anomaly/AnomalySystem.cs:82` |

**脉冲流程**（`SharedAnomalySystem.cs:70-116`）：
1. 若 Stability > 0.5：先按成长公式增加严重性：`ΔSeverity = (1 + max(Stability-0.5, 0) × 10) × 0.07`（`SharedAnomalySystem.cs:354-358`）
2. 稳定性随机浮动（上述 -0.1~0.15 × Severity）
3. 触发 `AnomalyPulseEvent`（带 powerMod = 行为 PulsePowerModifier），各效果系统响应
4. 每次脉冲管理日志记录

**成长阈值以上严重性增速**：GrowthThreshold = 0.5、SeverityGrowthCoefficient = 0.07（`AnomalyComponent.cs:81,87`）。例：稳定性 0.8 时每次脉冲 ΔSeverity = (1+3)×0.07 = 0.28。

## 三、超临界（Supercritical）事件

严重性达到 1 → 开始超临界动画（默认 **10 秒**，`AnomalyComponent.cs:149`）→ 播放 SupercriticalSoundAtAnimationStart → 动画结束后触发 `AnomalySupercriticalEvent`（`SharedAnomalySystem.cs:136-190`）→ 生成**活性核心**（CorePrototype）并删除异常本体。

- 超临界动画时长可按类型覆写：重力异常 15s（`anomalies.yml:131`）
- 结束方式二：**生命值归零**（收容粒子打太多）→ 直接终结，生成**惰性核心**（CoreInertPrototype），无超临界（`SharedAnomalySystem.cs:301-319`）
- 终结统一走 `EndAnomaly`：广播 `AnomalyShutdownEvent` → 生成核心（超临界→活性 / 衰减→惰性）→ 删除实体（`SharedAnomalySystem.cs:200-250`）
- 超临界时连接中的异常容器也会爆炸（`AnomalySystem.Vessel.cs:93-96`，见第七节）
- 管理命令：`pulseanomaly <uid>` / `supercriticalanomaly <uid>`（`AnomalySystem.Commands.cs:14-21`）

异常体有四类效果，每类绑定一种**异常粒子类型**（Delta/Epsilon/Zeta/Sigma 四选一，每个异常出生时从四类中**不重复随机分配**，`AnomalySystem.cs:98-108` ShuffleParticlesEffect；`ShuffleParticlesOnMapInit` 星光默认 true，`AnomalyComponent.cs:208`）：

## 六、研究点产出与容器（Anomaly Vessel）

**点产公式**（`AnomalySystem.cs:182-204`）：

```
multiplier = 1
  若 Stability > 0.5：× 1.5（GrowingPointMultiplier，不稳定奖励）
  × (1.5^Health - 0.5)              ← 健康惩罚，生命越低扣越多，最高扣 50%
  × 行为 EarnPointModifier
severityValue = 1 / (1 + e^(-7 × (Severity - 0.5)))   ← S 形曲线
点数/秒 = (Max - Min) × severityValue × multiplier + Min
```

| 参数 | 默认 | 说明 | 源码 |
|---|---|---|---|
| MinPointsPerSecond | 10 | 严重性 0 时 | `AnomalyComponent.cs:244` |
| MaxPointsPerSecond | 70 | 严重性 1 时（不含不稳定加成） | `AnomalyComponent.cs:251` |
| GrowingPointMultiplier | 1.5 | 不稳定状态（Stability>0.5）加成 | `AnomalyComponent.cs:258` |

例：严重性 0.5、健康 1、Balanced 行为 → severityValue = 1/(1+e⁰) = 0.5 → (70-10)×0.5×1+10 = **40 点/秒**。

**异常容器（Anomaly Vessel）**：手持扫描仪扫描异常后，把**扫描仪对容器使用**即可绑定（`AnomalySystem.Vessel.cs:54-71`）。绑定后：
- 通电时向科研服务器输出 `GetAnomalyPointValue × PointMultiplier`（`AnomalySystem.Vessel.cs:73-79`）
- 实验型容器（MachineAnomalyVesselExperimental）**PointMultiplier = 2**，代价：持续辐射源（强度 0.75、斜率 0.1）且爆炸更猛（总强度 500 vs 普通 30，`anomaly_equipment.yml:92-115`）
- 容器报警蜂鸣：异常失稳/衰减时按危险程度 2s→0.75s 缩短间隔（`AnomalySystem.Vessel.cs:139-167`；`AnomalyVesselComponent.cs:33-39`）
- 绑定后异常死亡（衰减）→ 容器解除绑定；**超临界 → 容器直接爆炸**（`AnomalySystem.Vessel.cs:81-97`）

**异常同步器（Anomaly Synchronizer）**：将异常活动转为设备信号（`Content.Shared/Anomaly/AnomalySynchronizerSystem.cs` + `AnomalySynchronizerComponent.cs`）：

| 参数 | 值 | 源码 |
|---|---|---|
| AttachRange | 0.4 格 | `AnomalySynchronizerComponent.cs:39` |
| CheckFrequency | 1s | `AnomalySynchronizerComponent.cs:45` |

## 八、稳定器 / 抑制器体系

星光/官方没有名为"稳定器"的独立设备，稳定手段分三层：

1. **Sigma 收容粒子**（APE 发射）：每次命中 生命 -0.05、稳定性 -0.1（`AnomalousParticleComponent.cs:41-48`）——把异常从成长区拉回稳定区，代价是生命；打过量（Health<0）异常消失出惰性核心（`SharedAnomalySystem.cs:308-312`）
2. **零空间稳定器交互**（星光独有）：APE 换装 CosmicLambdaParticle 弹头，对 PortalShadekin / CosmicMalignRift 类异常持续照射 60s → 强制 EndAnomaly（详见第四节）
3. **反异常区域（AntiAnomalyZone）**：半径 10 格内**异常生成器不会生成异常**（`AnomalySystem.Generator.cs:131-145`；`AntiAnomalyZoneComponent.cs:14`）
4. **同步器 Stabilize 端口**：异常进入稳定区间时输出信号供自动化（`AnomalySynchronizerComponent.cs:55`）

⚠️ 稳定性语义注意：**Stability 数值越大越危险**（>0.5 成长、<0.15 衰减），"稳定"区间是 0.15~0.5 之间，不是越高越好。

## 十一、异常核心与产物

**核心生成**：超临界 → 活性核心；健康归零/衰减 → 惰性核心（`SharedAnomalySystem.cs:229-233`）。

**活性核心生命周期**（`SharedAnomalyCoreSystem.cs:90-111` + `AnomalyCoreComponent.cs`）：

| 参数 | 值 | 说明 |
|---|---|---|
| TimeToDecay | 600s（10 分钟） | 过期变惰性（视觉 "decay" 层） |
| StartPrice | 10000 信用点 | 新鲜核心出售价 |
| EndPrice | 200 信用点 | 完全惰化后 |
| 价格衰减 | 线性插值：价格 = Lerp(End, Start, 剩余时间/600) | `AnomalyCoreSystem.cs:19-26` |

## 十二、体内异常（注入器 / 陷阱）

**注入器（AnomalyTrap*）**：静态陷阱装置，碰撞到带 `AnomalyHost` 标签或有心智的生物时，把整套异常组件注入其身体并自毁（`InnerBodyAnomalySystem.cs:72-83`；`anomaly_injectors.yml`）。共 10 种（火/电/暗影/冰/植物/蓝移/血肉/重力/科技/岩石 + Funky 层 CosmicAnomalyTrap；Santa 注释禁用），生成于异常生成器的 rare 池（30%）。

**宿主体验**：
- 注入即 4s 眩晕+抖动（`InnerBodyAnomalyComponent.cs:29`），获得 **ActionAnomalyPulse 主动脉冲能力**（`anomaly_injections.yml:9-11`）
- 严重性 50%/75%/90%/100% 四档服务器消息警告（`InnerBodyAnomalySystem.cs:145-187`）
- 宿主死亡 → 异常自动终结（health -2，`InnerBodyAnomalySystem.cs:199`）；**超临界 → 宿主直接碎尸**（`InnerBodyAnomalySystem.cs:142`）
- 注入的 Anomaly 组件：`deleteEntity: false`（不删宿主）、**MaxPointsPerSecond = 100**（比野外高）、脉冲间隔 60-120s（`anomaly_injectors.yml` 各 Trap 的 injectionComponents）
- 体内效果数值弱化版：如火异常引燃半径 3/火球 1-3 发（`anomaly_injections.yml:18-35`）、电异常闪电 1-3/电击范围 4/伤害 10/4s（`anomaly_injections.yml:44-49`）

## 十三、疑点清单

1. ⚠️ **"稳定器"命名**：任务书问"稳定器/抑制器"——源码无同名设备；实际稳定手段是 Sigma 收容粒子 + 星光零空间稳定器交互（APE 60s 照射），文档按实现写，无独立设备
2. ⚠️ **首脉冲 3 倍延迟**（`AnomalySystem.cs:82`）：星光注释 "longer the first time"，但 `OnMapInit` 后若 CanPulse 才设置——与官方"首次脉冲按正常间隔"不同，属 fork 有意改动
3. ⚠️ **GetPulseLength 注释与实现**：注释说"低于阈值返回最大间隔"，实际公式 `modifier = clamp((Stability-0.5)/0.5, 0, 1)` 在 Stability<0.5 时恒为 0 → 恒返回 MaxPulseLength，两者一致；但稳定性 0.5-1.0 之间线性压缩间隔，稳定性 0.75 时间隔 = 中点值——**稳定性越高脉冲越频繁**
4. ⚠️ **研究点公式的 Health 惩罚**：`1.5^Health - 0.5`，Health=1 时 = 1.0（无惩罚）、Health=0 时 = 0.5（-50%）——生命值满时健康惩罚恒为 0，只有受伤才扣
5. ⚠️ **OmegaStrong 粒子治疗异常**（`projectiles.yml:776` healthPerWeakeningeHit: 1）：官方粒子中唯一"治疗"弹头，仅供管理员/特殊事件（HideSpawnMenu），无正常获取途径
6. ⚠️ **Santa 异常与陷阱**：`RandomAnomalySpawner` 中注释掉 `AnomalySanta`（`anomaly.yml:25`），原型保留但玩家正常流程不会遇到（事件/管理员可刷）
7. ⚠️ **体内异常死亡判定**：宿主死亡时 `ChangeAnomalyHealth(ent, -2)` 强制终结（`InnerBodyAnomalySystem.cs:199`），但 `BeforeRemoveAnomalyOnDeathEvent` 可取消——存在可阻止该行为的 mod 接口，默认无
8. ⚠️ **APE 的 DoAfter 机制依赖**：零空间稳定交互要求射手=APE（Emitter 机器本体），且 APE 断电即中断（`AnomalySystem.cs:415-418`），玩家不能手持发射 CosmicLambdaParticle——只能操作 APE
9. ⚠️ **Tech 异常超临界 emag**：40% 概率对被链接设备触发 `GotEmaggedEvent`（`TechAnomalyComponent.cs:45`）——超临界可能把无辜设备刷成 emag 状态，影响安保判断
10. ⚠️ **AnomalyVessel 实验型**：pointMultiplier=2 但辐射源 0.75 会长期污染环境（`anomaly_equipment.yml:103-107`），且爆炸参数总强度 500 vs 普通 30——高危设备，Guidebook 未强调
