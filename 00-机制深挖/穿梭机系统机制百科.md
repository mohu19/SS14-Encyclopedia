## 2. 推进与转向物理

### 2.1 推进器组件（`ThrusterComponent.cs:11-70`）

| 字段 | 默认值 | 说明 |
|---|---|---|
| Thrust | 100 | 线性推力，方向由朝向决定 |
| Type | Linear | Linear=直线 / Angular=旋转（陀螺仪） |
| RequireSpace | true | 喷口必须暴露太空 |
| damage | Heat 40 | 灼烧伤害（每 2s tick，`FireCooldown`） |
| FireCooldown | 2s | 烧蚀伤害结算间隔 |
| Enabled | true | 是否可用（星光禁用了手动开关：`ThrusterSystem.cs:44` 订阅被注释） |

- **开启条件链**（`CanEnable`，ThrusterSystem.cs:430-449）：Enabled → 已锚固 → **APC 供电** → RequireSpace 时为喷口对太空（`NozzleExposed`，:451-461，喷口前方 1 格必须是太空）。`TileChangedEvent` 会在喷口被堵后自动熄火（:94-135）。
- **推力累计**：线性按 4 卡迪纳方向存 `LinearThrust[4]`，旋转存 `AngularThrust`；推力中心 `CenterOfThrust` 按推力加权刷新（:338-364）。
- **推进器燃烧碰撞体** `thruster-burn`（BurnPoly 默认梯形 "-0.4,0.5 … 0.4,0.5"），硬碰撞 + 每 2s 对触碰实体施加 Heat 40/120（`Update` :465-487）。

### 2.2 移动物理（星光重写 `Content.Server/_Starlight/Physics/MoverController.cs`，975 行，对照官方 `Content.Server/Physics/Controllers/MoverController.cs` 689 行）

- **多驾驶员合流**：同一艘船多名驾驶员（含遥控货船台 `DroneConsoleComponent`）输入向量加和后按**人数归一**（:749-751），不会叠加。
- **线速度上限**：`ObtainMaxVel` = `BaseMaxLinearVelocity × v / √(horiz²+vert²)`（:640-658，`LinearThrust[i]/LinearThrust[i]` 只为取符号方向）。已到速且同向输入 → 输出 0（不再过冲，:921-922）。
- **刹车主刹车**：`brakeInput × BrakeCoefficient(1.5)`，通过相对速率选反向推进器点火，单 tick 不超过减速所需（:754-847）。
- **角速度**：torque = `AngularThrust × -angularInput`，并钳制到 `(±MaxAngularVelocity − ω)/torqueMul`（:935-960），即角速度硬顶 **4 rad/s**。
- **FTL 期间禁驾**：Starting/Travelling/Arriving 或 PreventPilot → `CanPilot=false`，输入全清（:970-973）。
- 移动输入底层：`HandleShuttleInput` 亚 tick 插值（:553-580），`strafe/rotate/brake` 三通道（:582-635）。

### 2.3 阻尼

- 非 FTL：`DampingModifier = BodyModifier(0.25)`，经 `TileFrictionEvent` 乘到摩擦上（`ShuttleSystem.cs:134,183-186`）；FTL 启动时置 0（:188-196）。网格 fixture 密度 0.5、恢复系数 0.1（`SharedShuttleSystem.cs:51-57`）。

## 3. FTL 超空间跳跃（`ShuttleSystem.FasterThanLight.cs`，1191 行）

### 3.1 时间轴（CVar 默认值 `Content.Shared/CCVar/CCVars.Shuttle.cs:82-121`）

| 阶段 | 时长 | 行为 |
|---|---|---|
| Starting 启动 | **5.5s**（shuttle.startup_time） | 全船待机声 + 屏幕震动（Trauma 0.7×进度累积），未扣安全带者**击倒 5s**（hyperspace_knockdown_time）+ 站在太空格上被抛出（速度 10、力 50） |
| Travelling 超空间 | **20s**（shuttle.travel_time） | 转移至 FTL 地图（网格间缓冲 5），以 **20 m/s** 匀速飞行（:440），轻微震动 |
| Arriving 到达 | **5s**（shuttle.arrival_time） | 出超空间，到站震动 1.2 Trauma + 相机后坐 |
| Cooldown 冷却 | **60s**（shuttle.cooldown，抵达船 10s） | `ArrivalsFTLCooldown`；可用组件 `FTLCooldownOverride` 覆盖 |

### 3.2 超空间机制

- **专用 FTL 地图**：按需创建，同名 "FTL"，所有 FTL 船同图依次排布并交错（`_index += width + Buffer`，Buffer=5）。
- **无 FTL 组件被留下**：`LeaveNoFTLBehind` 把带 `NoFTLComponent` 的实体留在原地图（:807-830）。
- **FTL 结束 `Smimsh` 压扁**：着陆范围 0.2 边界内非本网格实体——有 Body 的直接 Gib（记日志 "gibbed by the shuttle"），其余删除；带 `FTLSmashImmuneComponent` 免疫（:1123-1190）。
- **击倒判定**：`KnockOverKids` 只处理未 `Buckled` 的直系子实体；星光新增：**穿磁靴（MovedByPressureComponent 禁用）不击倒**（:792-796）。

### 3.3 目的地校验（`ConsoleFTL`，ShuttleConsoleSystem.FTL.cs:116-170）

1. `CanFTL`：无 FTL 进行中 → 质量 ≤ **300**（shuttle.mass_limit，`FTLMassLimit>0` 且船开 FTLMassLimits）→ 无 PreventPilot/PreventFTL（含地图层，:263 星光）→ ConsoleFTLAttemptEvent 可取消。
2. `CanFTLTo`（SharedShuttleSystem.cs:63-111）：同地图放行；目标需 `FTLDestinationComponent` 且 Enabled；`RequireCoordinateDisk` 时**坐标盘**必须在 console disk_slot 中匹配目标；BeaconsOnly 目标只许信标配 FTL；白名单 `Whitelist` 过滤。
3. `FTLFree`：目标点需在**射程 GetFTLRange 内**（星光：`min(组件 FTLRange, 服务器上限 game.admeme_shuttle_limit=1000)`，:179-194、StarlightCCVars.Game.cs:22-23）；避开 `FTLExclusionComponent` 禁跳区（默认半径 32，FTLExclusionComponent.cs）；目标缓冲 `maxExtent/2 + 8` 内无其他网格（FTLBufferRange=8）。

### 3.4 到达方式

- 停靠型 FTL：`FTLToDock` 先取合理对接配置，失败则`TryGetFTLProximity` 邻近降落（同心扩张 AABB，最多 5 次迭代；多网格场景随机角/随机 0~64 偏移；单网格贴坐标）。
- 星光兜底链：目标地图失效时依次回退 原地图 → 任意站网格地图 → 首地图（:504-553，上游直落第一地图）。
- 星光魔改：`GetDockingConfigAt` 找不到配置时**忽略角度重试任意端口**（:561-567）；`PriorityTag` 到站优先对接指定 tag 端口。
- 落点行星网格 → `Disable` 静态化；行星内 FTL 会压扁生物群系（`Smimsh` + `ShuttleFlattenEvent`）。

## 5. 对接系统（DockingSystem.cs，460 行）

- **机构**：两端口间创建 **WeldJoint**（刚体焊接，刚度/阻尼由 LinearStiffness(2, 0.7, mA, mB) 算出，:235-241），配合寻路 portal，双方舱门解锁并保持开启、`ChangeAirtight=false`（:281-303）。

- **自动门闩**：FTL 中 `SetDockBolts(true)` 全船对接门落栓（含应急船）（FasterThanLight.cs:443；:492 复位）。

## 6. 应急穿梭机 / 逃生舱（EmergencyShuttleSystem.cs 845 + .Console.cs 602）

### 6.1 呼叫与倒计时（CCVars.Shuttle.cs:126-191）

| 项 | 值 |
|---|---|
| 到站停靠时间 | **180s** |
| 非优先口/无法停靠倍率 | **1.6667× / 2×** |
| 提前发射授权窗口 | **10s**（authorize） |

- **星光定制**（.Console.cs:205-259）：
  1. 目标网格取 `StationData.MainGrids` 优先，其次最大格（EmergencyShuttleSystem.cs:332-342）。
  2. **逃生舱改降"疏散星球"**：不随应急船去中央，而是落在程序生成的星球（生物群系随机 Grasslands/Snow/Caves + 10 种矿层 + 3~5 处废墟，landing zone 中心，落点半径 25m 随机、四向随机旋转、startup 0s、hyperspace = TransitTime+1+错峰 i 秒）。

## 10. 疑点清单 ⚠️

1. **Guidebook"空手可开关推进器"与源码冲突**：星光注释了全部 ActivateInWorld 切换逻辑（ThrusterSystem.cs:44,63,67），`OnActivateThruster` 已不可达（:137 注释自承）——当前版本推进器**不可手动启停**，文档文本过时。
2. **"FTL 冲量只走 4 卡迪纳向"**：`HandleShuttleMovement` 注释 "Won't just do cardinal directions"，但实际输入强制按输入角合并到相邻两个卡迪纳（:864-910），对角并非直线 45°——属实现限缩。
3. **逃生舱"扩容"**：上游逃生舱随应急船去中央，星光整段替换为"疏散星球"；若 `SetupEvacuationPlanet` 失败（try/catch 置空），`_evacuationLandingZone` 为 null → 该逃生舱**原地不动直到回合结束**（.Console.cs:230-234 只 Log.Error 不处理）。
4. **`EmergencyShuttleDockTimeMultiplierOtherDock=1.6667`**：非整倍率有意为之（多站台最差取 max），但 0.6667 的零头来源注释未说明。
5. **Admeme 上限 1000** 是硬顶（`min(FTLRange, 1000)`）：巨型船即使原型写了 2000+ 射程也飞不出 1000。
6. **应变船 FTL 时 `PriorityTag=DockEmergency`**（EmergencyShuttleSystem.cs:250-256 星光）：应急船会在到达时忽略角度抢任何 DockEmergency 口——可能与玩家在建的泊位冲突。
7. **`EmergencyShuttleAuthorizeTime=10s` 与早发窗口**：`EarlyLaunch` 要求 `_consoleAccumulator <= _authorizeTime` 才可授权，即**只有最后 10s 内能抢跑**，且 `EmergencyEarlyLaunchAllowed` 默认 false 时控制台 UI 根本打不开（SharedEmergencyShuttleSystem.cs:27-35）——两条路径并存易混淆。
8. **Scylla fireCost=12000"一发清空电池"**与 `burstCooldown 35s` 双限制；弹药注释 `# consumes the entire battery per shot`。
9. 官方 7 型舰炮**全部 DoNotMap**（cannons.yml:1 自述"station are completely unequipped to deal with ship combat"），但星光又给它们加 AutoLoader——若官方型被事件启用地图加载，数值存在但站图不会用。
