# 犯罪记录
犯罪记录控制台在每座空间站的安保部门都可以使用，用于追踪和管理船员名单中任何人的犯罪历史与状态。


[安保记录计算机](../00-实体清单/Structures.md)


任何人都可以打开控制台的界面，但只有拥有安保权限的人才能修改任何内容。

界面由以下元素组成：
- 一个搜索栏，旁边有一个筛选器，可以按姓名、指纹或 DNA 筛选船员。

- 一份船员名册列表，选择其中一个条目会显示该船员的犯罪记录。列表会随搜索栏内容过滤，所以想纵览全局的话，记得把搜索栏清空！

- 犯罪记录本身

- 船员列表下方的筛选按钮可以用来只显示被通缉、被拘留或获假释的船员。
在记录区你可以：
  - 查看船员的安保相关信息，如姓名、指纹和 DNA。

  - 在 <span style="color:gray">无</span>、<span style="color:yellow">被通缉</span> 和 <span style="color:red">被拘留</span> 之间更改安保状态。设置为“被通缉”时，系统会要求你填写理由。

  - 如果某人被通缉，你可以在状态下拉框下方看到理由。

  - 一旦某人被逮捕，请在控制台上更新他们的状态，让所有人都知道他们不再需要被缉拿。

  - 在他们服完刑期后，释放他们并把状态更新为“无”，以免有人认为他们是越狱逃犯。

  - 打开犯罪历史窗口查看或修改记录。

犯罪历史窗口列出某人的罪行，可以通过多种方式修改：
  - 自动修改：只需将某人的状态设置为“已逮捕”。理由会被添加到“ARRESTED:”条目下，这样自动生成的记录很容易辨认。

  - 添加新记录：点击“Add”并在输入框中填写内容。添加记录时，记得注明罪行和刑期，控制台会自动插入班次时间，你不需要手动填写！

  - 选中一行不需要的历史记录并点击“Delete”删除。非常适合清理小丑偷走 ID 卡之类的记录。

现在，你可以成为你一直想当的办公室文员了。
