革命者是受 <span style="color:yellow">苏维埃社会主义行星联盟</span>(Union of Soviet Socialist Planets) 雇佣的转化型敌对角色，他们的任务是夺取任意空间站的控制权，包括 <span style="color:#5346e0">你们</span> 的。

## 目标

你必须将站上所有的 [指挥人员](../08-事件与管理/15-指挥部.md) 转化、铐住或杀死，顺序不限。

你的目标**不是摧毁空间站**，而是*夺取它*，所以尽可能减少破坏。

如果所有 **<span style="color:#ed7300">首席革命者</span>** 都死了，**革命就会失败**，届时所有 <span style="color:red">革命者</span> 都会解除转化。

## Svyaz-UZL 上行链路（Telebonds 与 Total Conversion）

<span style="color:#ed7300">首席革命者</span> 开局还额外拥有一个 <span style="color:#ed7300">SKB 上行链路植入器</span>，它可以植入到首席革命者自己体内，或植入到**由他们亲自转化**的 <span style="color:red">革命者</span> 体内。


[苏维埃升链植入器](../00-实体清单/Objects.md)

  [“联络-UZL”无线电](../00-实体清单/Objects.md)

皮下上行链路允许通过 **<span style="color:#5c5c5c">Telebonds</span>** 和 **<span style="color:#e3a736">Total Conversion</span>** 购买革命所需的各类**全球限量库存**武器与工具。

- **<span style="color:#5c5c5c">Telebonds</span>** 与 <span style="color:red">传电晶体</span> 非常相似，是一种通过**转化**获得的个人私有货币，每个 <span style="color:#ed7300">首席革命者</span> 各自持有。
- **<span style="color:#e3a736">Total Conversion</span>** 除了显示有多少船员被转化之外，还是一份**所有 <span style="color:#ed7300">首席革命者</span> 共享的得分**。它主要用于上行链路的 **GLOBAL** 栏目，让你可以放置诸如 <span style="color:yellow">补给裂隙</span> 之类的东西。

每当一名 **<span style="color:#ed7300">首席革命者</span>** 转化某人时，他们私下获得 **<span style="color:#5c5c5c">1 Telebond</span>**，全局获得 **<span style="color:#e3a736">1 Total Conversion</span>**。

请记住，**<span style="color:#e3a736">Total Conversion</span>** 是一份**全局进度得分，而非货币**，一旦你达到一定的转化数量，就可以免费获得物品。

上行链路的库存对所有使用该上行链路的人共享，此外它还会显示最后购买该物品的人是谁。

## 补给裂隙

当累计转化达到 **20 人**时，你将能够放置一个 <span style="color:yellow">补给裂隙</span>，它会每 35 秒投放一次苏维埃补给。


[SKB军备裂隙](../00-实体清单/Objects.md)

  [SKB军械箱](../00-实体清单/Objects.md)

[卡尔达肖夫-莫辛](../00-实体清单/Objects.md)


<span style="color:yellow">裂隙</span> 生成时，会**在聊天中秘密告知所有 <span style="color:red">革命者</span> 它的位置**。

当充能达到 50% 时，空间站**将收到能量涌入的警报**，从而**暴露你**——但从长远来看，换来的是无限补给。

如果 <span style="color:yellow">裂隙</span> 被摧毁，你将无法再放置另一个。只有**当前的裂隙充能完毕**，你才能放置下一个。

建议在回合早期就和你的 <span style="color:red">革命者</span> 讨论好把 <span style="color:yellow">裂隙</span> 放在哪里，这样他们就能**加固**该区域，防止 <span style="color:#cb0000">安保部门</span> **摧毁**它。
