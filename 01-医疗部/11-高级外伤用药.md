# 特种外伤化学品

  纳米传讯最伟大的科学家们又合成了三种更具针对性的外伤化学品！每一种都能治愈一种特定的伤害亚型。





  # Razorium

  <span style="color:red">务必小心</span>使用上述特种外伤化学品。如果将其与不同类型的另一种外伤化学品混合，产生的混合物会生成一种名为 Razorium 的危险化学品！

  为避免这种情况，请确保患者先代谢完一种外伤药物，再给他们另一种。留意他们生命值变化的速率。

  **一些会生成 Razorium 的混合示例：**

  Bicaridine 与 Puncturase

  Puncturase 与 Lacerinol

  Bruizine 与 Bicaridine

  Lacerinol 与 Bruizine

  请注意，这 4 种化学品的**任意**组合都很可能混合并生成 Razorium！制作这些化学品时要格外小心，因为它们都含有 Bicaridine。任何残留的 Bicaridine 都很可能混合生成 Razorium！
