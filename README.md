## 🔧 工具链（`projects/SS14-Starlight/tools/`）

- `extract_guidebook.py` — 388 条目提取（zh-CN 优先）
- `organize_volume.py` — 条目 → 部门卷（自动编号/幂等/链接转换）
- `import_translations.py` — 中文译文导入
- `extract_entities.py` — 实体全清单（17,597）
- `link_entities.py` — `[[实体:X]]` → 实体清单链接（1,276 处）
- `audit_coverage.py` — 覆盖核验（XML vs 条目，19 个遗漏已补录）
- `verify_outputs.py` — 常驻回归（条目数/编号/残留/数值抽查）
