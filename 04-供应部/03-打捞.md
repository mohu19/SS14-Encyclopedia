# 打捞

  <span style="color:cyan">打捞</span>是货运部关键但也最危险的收入来源之一。打捞从<span style="color:cyan">太空残骸</span>和神秘的<span style="color:cyan">采矿小行星</span>中提取金钱。

  虽然太空的虚空充满了恐怖，但只要准备充分、协调得当，任何打捞队都能为货运部赚到很多钱。

  ## 准备

  在离开空间站之前，确保你准备好了所有必需的装备。否则，你很可能在见到任何利润之前就死掉！

  离开空间站前所需的一切都提供在打捞部的起始房间内。虽然科学部可以研究更好的武器和装备，但最好带着你的起始装备出发，而不是什么都没有。




[太空作业员硬装宇航服](../00-实体清单/Clothing.md)

[磁力靴](../00-实体清单/Clothing.md)

[气罐供应机](../00-实体清单/Structures.md)




  你最基本需要的装备是EVA套装。

  - <span style="color:cyan">太空员硬质宇航服</span>：这能让你在太空中存活。*记住要启动头盔才能呼吸，并打开其内置的手电筒*。
  - <span style="color:cyan">磁力靴</span>：这能让你在探索太空残骸时有重力，同时让你不会滑倒。
  - <span style="color:cyan">氧气/氮气</span>：根据你的物种，你需要<span style="color:cyan">氮气</span>（史莱姆和沃克斯）或<span style="color:cyan">氧气</span>（其他所有物种）。<span style="color:cyan">气罐分配器</span>有你需要的所有气罐，所以多备一些。




[原型动能加速器](../00-实体清单/Objects.md)




  所有打捞专家都必须武装自己，以防需要抵御敌对生物。

  - <span style="color:cyan">原型动能加速器</span>：这把枪有无限的弹药，让你可以缓慢地采矿并在太空中飞行。科学部可以打印升级件，让它伤害更高、射程更远、射速更快。




[镐](../00-实体清单/Objects.md)

[矿石袋](../00-实体清单/Objects.md)



  虽然从技术上讲，你只用一把PKA和一个背包就能采矿和收集矿石，但打捞员一开始就有更专业的装备来做这项工作。

  - <span style="color:cyan">镐</span>：双手持握时，这是以任何合理速度采矿所必需的。它也是一把称手的近战武器！
  - <span style="color:cyan">矿石袋</span>：装备在腰带栏位时，它会磁化附近的矿石并自动为你拾取。




[灭火器](../00-实体清单/Objects.md)

[抓钩枪](../00-实体清单/Objects.md)

[打捞专员PDA](../00-实体清单/Objects.md)

  虽然你可以获得更高级的移动方式，但你一开始会使用更朴素的方法。

  - <span style="color:cyan">灭火器</span>：穷人的喷气背包。在太空中，你可以利用灭火器的击退力向相反方向推进自己。它可以用任何液体重新填充。
  - <span style="color:cyan">抓钩枪</span>：一件潜力无限的移动工具。它像其他枪一样发射，可以通过重新装填来收回。一旦你钩住了什么东西，点击<span style="color:yellow">**[keybind="UseSecondary"]**</span>把自己拉过去。
  - <span style="color:cyan">打捞PDA</span>：你的PDA自带已安装的AstroNav GPS程序，让你可以在手持时把它当作GPS使用。出发前一定要记下空间站的坐标！
  - <span style="color:cyan">质量扫描仪电脑</span>：一台提供空间站及附近太空实体俯视图的电脑控制台。在前往残骸或小行星之前，用它仔细检查它们的位置和方向。

  - <span style="color:cyan">手持无线电</span>：即使常规无线电通信不可用，这也能让你与其他打捞专家通信。
  - <span style="color:cyan">全球定位系统</span>：一个备用的GPS系统，与你PDA中预装的相同。作为备用选项或作为新雇佣打捞员的装备很有用。
  - <span style="color:cyan">工具腰带</span>：这能装下你从打捞残骸和采矿小行星上搜刮机器等所需的所有装备。只要你不打算采矿，就戴上它。

  ## 打捞磁铁牵引

  一旦准备好，就该去探索星辰了。




[打捞磁铁](../00-实体清单/Structures.md)




  <span style="color:cyan">打捞磁铁</span>是把太空残骸拉到附近太空中的机器。

  打捞磁铁提供五个选项：它们将是<span style="color:cyan">小行星</span>、<span style="color:cyan">打捞残骸</span>和<span style="color:cyan">太空残骸</span>的随机组合。选择其中一个选项后，被选中的区域将在接下来的**6分钟**内被拉过来。在这段时间结束时，被拉过来的网格上剩余的任何战利品都会消失。如果这些选项看起来都不吸引人，它们会在无人认领的情况下每**3分钟**刷新一次。

  在这6分钟内，飞到被拉过来的区域，尽可能提取所有利润，然后飞回空间站。

### 小行星




[镐](../00-实体清单/Objects.md)

[矿石袋](../00-实体清单/Objects.md)

[矿石处理机](../00-实体清单/Structures.md)




  打捞磁铁提供小行星上资源类型的信息，这可以帮助你根据空间站当前的需求决定优先选择哪一个。这是一个相对安全的采矿选项，因为小行星上没有敌意生物——尽管肯定仍然存在威胁……

  你只需要飞过去，用你的<span style="color:cyan">镐</span>和<span style="color:cyan">矿石袋</span>采矿。收集完所有矿石后，你可以通过<span style="color:cyan">矿石处理器</span>把它精炼成材料。

  小心行事——在看似普通的岩石中，隐藏着大块<span style="color:red">吉布顿矿</span>，只要稍微扰动就会爆炸。

### 太空残骸




[扳手](../00-实体清单/Objects.md)

[灭火器](../00-实体清单/Objects.md)

[回收机](../00-实体清单/Structures.md)




  <span style="color:cyan">太空残骸</span>是一个多用途的选择，提供班次开始时短缺的关键基础材料（如钢、玻璃等）。物品和废料散落在残骸上，必须收集起来。考虑拖一个残骸上的储物柜或板条箱，方便储存。

  残骸上散布着许多威胁。嗜血的<span style="color:red">太空鲤鱼</span>和<span style="color:red">鲨鱼米诺鱼</span>出没其中，急于冲向靠近的打捞员。<span style="color:red">地雷</span>也罕见地出现在残骸上，能够使毫无防备的探险者失去行动能力。

  从残骸回来后，把你发现的任何废料放进部门的<span style="color:cyan">回收机</span>，把它变成有用的材料，然后交给货运部分发给空间站。如果你在残骸上找到贵重物品，如<span style="color:yellow">硬币、戒指和手表，</span>把它们交给货运部，以便在<span style="color:cyan">自动贸易站</span>出售获利。

  ## 成长与升级

  虽然你的起始装备足以让你在基本层面上完成工作，但高级装备会让你的工作轻松得多，并给你必要的装备来应对可怕的<span style="color:red">采矿小行星</span>。

  ### 打捞任务板




[打捞任务板](../00-实体清单/Structures.md)




  <span style="color:cyan">打捞任务板</span>是位于打捞舱的一台电脑。它是打捞部版的<span style="color:cyan">货运悬赏电脑</span>，允许打捞员用打捞部特有的材料完成特定任务，以赚取斯佩索并解锁<span style="color:yellow">高级打捞装备</span>。

  一旦你收集齐完成任务所需的物资，打印一份<span style="color:cyan">打捞任务发货标签</span>，把它贴到装有货物的板条箱或储物柜上。你可以使用<span style="color:cyan">估价工具</span>仔细检查它是否准备好出售。准备好的悬赏货品然后可以带到<span style="color:cyan">自动贸易站</span>，赚取货运斯佩索，并在<span style="color:cyan">货运订购电脑</span>中解锁新的打捞专用板条箱。




[富尔顿回收装置](../00-实体清单/Objects.md)

[破碎锤](../00-实体清单/Objects.md)

[震波炸药](../00-实体清单/Objects.md)




  完成打捞任务会提升你的等级，并在<span style="color:cyan">货运订购电脑</span>中解锁新的装备购买，包括：

  - <span style="color:cyan">富尔顿回收装置</span>：一旦富尔顿装置与富尔顿信标链接，它们可以被附在未锚定的结构上，如板条箱或机器，在一小段等待后把它们传送回信标。对于移动物品和人来说都非常有用。
  - <span style="color:cyan">粉碎者武器</span>：一系列供打捞员购买的高级近战选项。<span style="color:red">粉碎者匕首</span>是你生存刀的升级版，自动挥砍，速度比普通刀快得多。<span style="color:red">粉碎者</span>和升级版<span style="color:red">粉碎者长柄刀</span>是巨大的长柄武器，双手持握时可以发射特殊的弹丸。这些弹丸本身不造成伤害，但如果被标记的敌人被足够快地近战攻击，你会吸取他们的一些生命来治疗自己。所有粉碎者武器都自带内置泛光灯。
  - <span style="color:cyan">地震炸药</span>：采矿炸药，用于炸开小行星或破入危险的残骸。记住你可以把它们链接到远程引爆器，或设置它们在被附着到墙上时开始引爆，以实现更安全的拆除。

  ### 与科学部合作




[科学家手办](../00-实体清单/Objects.md)

[研点盘（1000个）](../00-实体清单/Objects.md)



  <span style="color:purple">科学部</span>是打捞部至关重要的伙伴。科学部依赖打捞部提供基础材料（钢、塑料、玻璃）和高级材料（银、金、等离子体、铀），而打捞部依赖科学部提供让工作更轻松的升级装备。

  只要有可能，与科学部沟通并尽量优先处理他们的请求。虽然科学部需要大量的基础材料，但他们完全依赖你供应<span style="color:yellow">金、银和铀，</span>这些都需要用于你的高级装备。如果你想让科学部帮你，你必须帮他们——反之亦然。




[采矿钻机](../00-实体清单/Objects.md)

[手持质量扫描仪](../00-实体清单/Objects.md)

[PKA改装套件（射程）](../00-实体清单/Objects.md)




  科学部是各种极其有用装备的唯一来源，包括：

  - <span style="color:cyan">采矿装备</span>：科学部可以为你提供<span style="color:yellow">采矿钻机和矿物扫描仪</span>，让采矿更快更容易。他们还可以为你建造<span style="color:yellow">工业矿石处理器</span>，以更好的比率把矿石加工成成品材料。
  - <span style="color:cyan">手持质量扫描仪</span>：一台口袋大小的便携式质量扫描仪电脑。虽然使用它需要电池，但它让你可以在太空中任何位置查看自己的位置。
  - <span style="color:cyan">PKA升级</span>：你可以从三个升级中选择最多两个独特的升级来升级你的PKA：<span style="color:red">伤害，</span><span style="color:yellow">射速，</span>和<span style="color:green">射程</span>。

  ## 采矿小行星

  一旦你觉得已经掌握了打捞磁铁，遥远的<span style="color:red">采矿小行星</span>就是打捞员旅程的下一步。到达采矿小行星通常需要穿梭机或喷气背包，而且由于其中的异常危险，通常不应该独自探索。




[歌利亚](../00-实体清单/Mobs.md)

[蜂巢领主](../00-实体清单/Mobs.md)

[蛇怪](../00-实体清单/Mobs.md)




  采矿小行星由两个部分组成：<span style="color:cyan">地牢</span>，一个充满敌人和材料战利品的随机生成结构，以及<span style="color:cyan">小行星</span>，包含大量矿物财富，点缀着战利品和怪物的口袋。

  当心采矿小行星上的怪物，它们远比残骸和太空残骸上的威胁强大。

  - <span style="color:cyan">歌利亚</span>：巨大的野兽，可以用缠绕的触须使目标失去行动能力，让他们在巨大的爪子和咬合的牙齿面前毫无还手之力。它们很难打倒，但它们可以被屠宰，获得珍贵的<span style="color:cyan">歌利亚皮甲片，</span>对完成打捞任务和升级你的太空员服都很有用。
  - <span style="color:cyan">蜂巢领主</span>：移动迅速且行为怪异的异常体。它们在战斗中喜欢保持距离，喷出小的<span style="color:cyan">蜂巢幼体</span>来蜂拥攻击打捞员。它们不是特别耐打，所以迅速伏击它们，以免它们召唤一大群把你淹没。它们可以被屠宰，获得快速腐烂的<span style="color:cyan">蜂巢核心，</span>用于完成打捞任务，也可以生吃来快速治疗。
  - <span style="color:cyan">蛇怪</span>：潜伏在阴影中的冰封恐怖。蛇怪可以发射冰冻能量箭，伤害并减速目标，而且经常用它来削弱目标，然后上前了结。一旦被击败，它们可以被屠宰，获得无价的<span style="color:cyan">钻石矿石</span>。
