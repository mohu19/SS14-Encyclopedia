## 2. 基础物理：理想气体与常量

### 2.1 核心公式

大气的一切压力、温度、体积计算都基于理想气体方程：

```
P = n × R × T / V        （kPa）
```

- `n` = 总摩尔数（22 种气体之和），`R = 8.314462618` kPa·L/(K·mol)（气体常量，`Atmospherics.cs:15`）
- 实现在 `Content.Shared/Atmos/GasMixture.cs:49-55`；`Volume ≤ 0` 时压力强制为 0
- 温度写入时被钳制在 **[TCMB=2.7K, Tmax=262144K]** 区间（`GasMixture.cs:66`）；超过 Tmax 的物理含义是"任何气体都会变成等离子体"（`Atmospherics.cs:50-56`）
- 太空的默认混合体：体积 2500L、温度 2.7K（`GasMixture.cs:19` `SpaceGas`）

## 4. 气体反应（24 个有效）

### 4.1 反应执行规则

- 反应原型定义在 yaml（`- type: gasReaction`），行为实现是 C# 的 `IGasReactionEffect` 类（官方 7 个类含未启用的 WaterVaporReaction、Funky 14、星光 4，共 25 个类文件）
- 反应按 **priority 降序**执行（`AtmosphereSystem.Gases.cs:28` `Array.Sort(... b.Priority.CompareTo(a.Priority))`）；同优先级顺序不保证
- 每个反应检查：热能量 ≥ `minimumEnergy`、温度 ∈ [minimumTemperature, maximumTemperature]、每种气体摩尔数 ≥ `minimumRequirements[i]`（`Gases.cs:415-446`；原型默认值见 `GasReactionPrototype.cs:18-44`：默认最高温 +∞、最低温 TCMB=2.7K、优先级 int.MinValue）
- 温度检查用的是**反应前的温度**（`Gases.cs:418`），能量检查用反应前的总热能量 `GetThermalEnergy`
- 反应可返回 `StopReactions` 标志短路后续反应（`Gases.cs:447-449`）
- **超惰性气体守卫（Funky/星光反应标配）**：多数 Funky/星光反应文件开头统一判断 `if (mixture.Temperature > 20f && mixture.GetMoles(Gas.HyperNoblium) >= 5f) return NoReaction;`（如 `HydrogenFireReaction.cs:19-20`、`HyperNobliumProductionReaction.cs:14-15`、`BZProductionReaction.cs:18-19` 等）——**T>20K 且超惰性气体 ≥5mol 时直接不反应**
- 官方层反应**无**此守卫（等离子体/氚火只有 yaml 门槛）

#### 关键公式

- **等离子体火**（`PlasmaFireReaction.cs:21-63`）：`temperatureScale = clamp((T-373.15)/(1643.15-373.15), 0, 1)`（1370°C 以上 = 满效率）；`oxygenBurnRate = 1.4 - temperatureScale`；`supersaturation = clamp((O2/等离子体 - 32)/(96-32), 0, 1)`（过饱和时产氚，否则产 CO2）；`plasmaBurnRate` 受 `PlasmaOxygenFullburn=10` 与 `PlasmaBurnRateDelta=9` 限制；放热 `160e3 × plasmaBurnRate / heatScale`（heatScale 防加速导致温度爆表）
- **氚火**（`TritiumFireReaction.cs:22-51`）分两档：低能档（O2<氚 或 温度×热容×heatScale < `MinimumTritiumOxyburnEnergy=143000`，防单罐炸弹，`Atmospherics.cs:258`）`burnedFuel = min(O2/100, 氚)`；高能档 `burnedFuel = min(氚, O2/2)/10`，能量 = 2.84e6 × burnedFuel × 10；两档都产 `水蒸气 += burnedFuel`（1:1）
- **Frezon 制冷**（`FrezonCoolantReaction.cs:19-46`）：`scale = (T-23.15)/(373.15-23.15)`，T>373.15K 时 `energyModifier = min(scale, 10)`（越热制冷越猛）；`burnRate = Frezon × scale / 20`；耗 N2 = burnRate×5，产 N2O = burnRate×6；能量 = burnRate × (-600e3) × energyModifier
- **Frezon 生产**（`FrezonProductionReaction.cs:21-40`）：`efficiency = T/73.15`（**越热效率越高**——与 yaml 最高温 73.15K 自相矛盾，见疑点 4）；N2 是催化剂兼限速剂：`catalystLimit = N2 × (10/efficiency)`

## 5. 燃烧与火

### 5.1 点燃条件（`AtmosphereSystem.Hotspot.cs:197-257`）

`HotspotExpose` 在满足以下**全部**条件时点燃瓦片：

1. 氧 ≥ 0.5 mol（:209）
2. 等离子体 > 0.5 或 氚 > 0.5 或 氢 > 0.5（:237，Funky 扩展）
3. 超惰性气体 ≤ 5 mol（:218）
4. 暴露温度 > 373.15K（=T0C+100 = 100°C，`PlasmaMinimumBurnTemperature`，`Atmospherics.cs:249`）

点燃后初始火体积 = **暴露体积 × 25**（:246-253）。火花/点火源暴露体积为 50L（`IgnitionSourceSystem.cs:25`），即最小火焰 ≈ 1250L。

火维持（`ProcessHotspot`，:87-99）任一条件不满足即熄灭：温度 <373.15K、体积 ≤1L、无空气、O2 <0.5、三种燃料都 <0.5、超惰性气体 >5mol。

### 5.2 火的成长与蔓延（:101-158, 271-288）

- **Bypassing（全格火）**：火体积 > 空气体积×95% 时视为全格火，直接对整格空气做反应，火体积 = `ReactionResults[Fire] × FireGrowthRate(40000)`（`Atmospherics.cs:243`）
- **蔓延**：温度 > `FireMinimumTemperatureToSpread`（=T0C+150 = 423.15K，:240）时，向相邻格辐射温度 = 本格温度 × `FireSpreadRadiosityScale(0.85)`（:140），暴露体积 = 2500/4 = 625L（:150）
- 全格火每 tick 在格内烧焦痕迹贴花（上限 4 个）、播火焰音效（音量/音调随火状态 1-3 变化，:156-177）

### 5.3 燃烧伤害（`FlammableSystem.cs` + `FlammableComponent.cs`）

- 着火实体每 **1 秒**（`UpdateTime`，FlammableSystem.cs:57）结算一次：
  - 环境 O2 < 1 mol → 自动熄灭（:451-455）
  - 升温：`ChangeHeat(12500 × FireStacks)`（:461）
  - 伤害：`Damage × FireStacks × 防火乘数`（:470，防火乘数来自 `GetFireProtectionEvent` 装备抗性）
- FireStacks 钳制 [-10, +10]（FlammableComponent.cs:51,55），点燃默认 +2（:102），自然消退 -0.1/秒（:108）；**负值 = 湿身**，每秒回 1 直到 0（FlammableSystem.cs:433-436）；就地打滚（Resist）消退 ×15（:472），耗时 2 秒（FlammableComponent.cs:39）
- 瓦片火对实体：`fireStackMod = max(log2(ΔT/100)+1, 0)`（FlammableSystem.cs:406）

## 6. 管网（Pipenet）与管件

### 6.1 五层管道（Carpmosia 改，星光继承）

- 管道可在同一格堆叠 **5 层**而互不混气：`Primary / Secondary / Tertiary / Quaternary / Quinary`（`Content.Shared/Atmos/Components/AtmosPipeLayersComponent.cs:24` 与枚举 :117-126）
- 螺丝刀切换层的循环顺序被重映射为 **1 → 2 → 4 → 5 → 3**（Primary→Secondary→Quaternary→Quinary→Tertiary→回 Primary），方便施工（`SharedAtmosPipeLayersSystem.cs:180-188`）；切换耗时 1 秒（AtmosPipeLayersComponent.cs:85），需要螺丝刀工具（:79）
- 只有同层管道才互联（AtmosPipeLayersComponent.cs:11-12 注释）；换层会替换实体外观（每层独立 RSI，pipes.yml:96-104）

### 6.2 管网（PipeNet）模型

- 一条管网 = 一组连通的 `PipeNode`（`nodeGroupID: Pipe`）聚合为一个 `PipeNet`（`Content.Server/NodeContainer/NodeGroups/PipeNet.cs`）
- **整个管网只持有一个 GasMixture**（`Air`，PipeNet.cs:23），体积 = 各管道节点体积之和（:50-59，单节管道默认 **200L**，`PipeNode.cs:108-110`）；气体在管道内**也会发生反应**（`Update() = React(Air, this)`，PipeNet.cs:45-48）
- 管网拆分成两组时，气体按新网体积比例 `DivideInto` 分配（PipeNet.cs:74-86）；删除节点时按 `1 - 管节体积/全网体积` 比例扣除气体（:70-72）
- 管网由大气主循环的 `PipeNet` 状态统一处理（`AtmosphereSystem.Processing.cs:534-563`，受 3ms 时间预算限制分帧跑完）

### 6.3 管道耐久

- 普通管道（`GasPipeSansLayers` 父原型）`Destructible` 阈值：**100 伤害 → 破裂**（生成 `GasPipeBroken` + 金属断裂音效 + Breakage），**200 伤害 → 直接毁坏**（Destruction，注释"for nukes"）（`Resources/Prototypes/Entities/Structures/Piping/Atmospherics/pipes.yml:23-47`）
- 破裂管（GasPipeBroken）覆写为 100 伤害直接毁坏（pipes.yml:389-396，防递归破坏）
- 管道价格 30 信用点（pipes.yml:67，星光）；可用 RPD 快速拆建（:68-74，星光）

## 7. 压力伤害与破空

### 7.1 气压伤害（`BarotraumaSystem.cs`，每秒结算一次，:26,260-267）

| 区间 | 判定 | 伤害 | 位置 |
|---|---|---|---|
| 低压危险 | 压力 ≤ **20 kPa**（`HazardLowPressure`） | `Damage × LowPressureDamage`，**LowPressureDamage = 2**（星光 nerf，上游 4→2，`Atmospherics.cs:443`），无视抗性 | BarotraumaSystem.cs:301-313 |
| 高压危险 | 压力 ≥ **550 kPa**（`HazardHighPressure`） | `Damage × min((P/550 - 1) × 4, 4)`，上限 **4**（`PressureDamageCoefficient=4`/`MaxHighPressureDamage=4`，:431-436） | :314-328 |
| 警告图标 | ≤50 kPa（=2.5×20） / ≥385 kPa（=0.7×550） | 仅警报级别 1（灰色/橙色图标） | :339-350 |

- 装备减压：低压用 `LowPressureModifier/Multiplier`，高压用 `HighPressureModifier/Multiplier`（取最弱部位，:102-200）；默认保护槽位 = 头（`BarotraumaComponent.cs:31`，星光把外衣移到替代槽位组 :37-38）；单实体累计伤害达 `MaxDamage = 200` 后停止结算（BarotraumaComponent.cs:20）
- **地图级免疫（星光）**：地图带 `PressureImmunityComponent` 时其上所有 Barotrauma 实体免疫气压伤害（BarotraumaSystem.cs:297-299）

### 7.2 压差伤害（ΔP，破窗）

| 强化玻璃 | 15000 | 10000 | Threshold | — |
| 等离子体窗 | 75000 | 50000 | Linear | 0.0005 |
| 强化等离子体窗 | 150000 | 100000 | Linear | 0.0001 |
| 1/4 玻璃 | 250 | 187.5 | Threshold | — |
| 1/4 强化玻璃 | 3750 | 2500 | Threshold | — |
| 1/4 等离子 | 18750 | 12500 | Threshold | — |
| 1/4 强化等离子 | 37500 | 25000 | Threshold | — |

（开关 `atmos.delta_pressure_damage`，默认开，`CCVars.Atmos.cs:161-162`）

### 7.3 气罐压力事故（`GasTankComponent.cs:83-101` + `GasTankSystem.cs`）

| 阈值 | 值 | 效果 |
|---|---|---|
| 泄漏 | 30 ATM（3039.75 kPa） | 开始缓慢漏气 |
| 破裂 | 40 ATM（4053 kPa） | 全部内容物喷入大气 |
| 碎爆 | 50 ATM（5066.25 kPa） | 3×3 爆炸，范围 = √((P - 50ATM)/2.25ATM)（`GasTankSystem.cs:226`）；爆炸半径由星光 CVar `atmos.max_explosion_range = 15` 封顶（`CCVars.Atmos.cs:152-153`，上游默认 26） |

### 7.4 太空风（压差抛飞）

## 8. 大气处理管线（Atmos 主循环）

### 8.1 状态机（`AtmosphereSystem.Processing.cs:848-861`）

```
Revalidate → TileEqualize(Monstermos) → ActiveTiles(LINDA) → ExcitedGroups
→ HighPressureDelta(太空风) → DeltaPressure(压差伤害) → Hotspots(火)
→ Superconductivity(超导，默认关) → PipeNet(管网) → AtmosDevices(设备)
```

共 10 个状态；每个状态内部又分帧处理（受 3ms 预算限制，`atmos.max_process_time`，`CCVars.Atmos.cs:122-123`）。

### 8.2 节拍

- `AtmosTime = 1/15s`（`atmos.tickrate=15`，CCVars.Atmos.cs:128-129）
- 设备实际节拍 `RealAtmosTime = (10 - 禁用状态数) × 1/15`（Processing.cs:570-582）；默认禁用超导 → **0.6 秒**一次
- 时间加速：`atmos.speedup = 8`（泵速 8 倍）；`atmos.heat_scale = 8`（换热/反应热量 8 倍，REPLICATED 客户端同步）（CCVars.Atmos.cs:137-145）

### 8.3 LINDA 换热（`AtmosphereSystem.LINDA.cs`）

- 相邻瓦片间逐气体交换：`Δ = (本格摩尔 - 邻格摩尔) / (相邻数 + 1)`（:228），质量守恒
- 气体浓度差过小（`MinimumMolesDeltaToMove`）或温度差 <4K 可挂起该方向交换（`Atmospherics.cs:124-148`）

### 8.4 Monstermos 破空均衡

- 连通区域 BFS 聚合上限 **200 格**（`MonstermosTileLimit`，Atmospherics.cs:222），硬限 **2000 格**（:217）；超限时只均衡前 200 格（Monstermos.cs:102-115）
- 触到太空 → `ExplosivelyDepressurize` 洪水填充：每周期逃逸 15% 剩余气体（`atmos.mmos_spacing_speed=0.15`），残余低于 **2.0 kPa** 直接清零（`atmos.mmos_min_gas=2.0`），单格限流 500 kPa（`atmos.mmos_max_wind=500`）（CCVars.Atmos.cs:73-89；Monstermos.cs:501-512）
- 泄压路径上的防火门会触发 `EmergencyPressureStop` 自动关舱（`ConsiderFirelocks`，Monstermos.cs:416,576-593）
- 开关：`atmos.monstermos_equalization=true`、`atmos.monstermos_depressurization=true`、`atmos.monstermos_rip_tiles=false`（不撕地砖）、`atmos.grid_impulse=false`（CCVars.Atmos.cs:42-67）

## 10. 疑点清单（如实记录，未擅自"修正"）

1. **反应总数修正**：上一版提取数据称"26 个反应"（7+16+4），实测为 **24 个有效反应**（6+14+4）。差异来源：官方 WaterVaporPuddle 整段被注释（reactions.yml:61-69），Funky 实际只有 14 条而非 16。C# 反应类文件共 25 个（含未启用的 WaterVaporReaction）。
2. **氚火质量不守恒**：高能档每 mol 氚消耗 0.5 mol O2（6g+16g=22g 输入），却只产出 1 mol 水蒸气（18g），少 4g；代码注释却写 "Conservation of mass is important"（TritiumFireReaction.cs:47-48）。
3. **氨的摩尔质量 = 44**（gases.yml:72）：化学上 NH₃ 应为 17，疑抄 CO2。
4. **Frezon 生产自相矛盾**：yaml 设最高温 73.15K（"Cold tritium fire"），代码却是 `efficiency = T/73.15` 越热效率越高（FrezonProductionReaction.cs:21），类注释也写 "paradoxically gets more efficient the hotter it is"（:10-11）。
5. **Halon 吸氧在 373K 以下也能部分反应**：yaml 门槛 373.149K，但效率公式分母是 `FireMinimumTemperatureToExist × 10 = 3731.5K`（HalonOxygenAbsorbtionReaction.cs:22）——若在管道内（无 yaml 门槛语境）低温也能缓慢吸氧。
6. **管道双阈值**：Destructible 100（破管）/200（碎毁）可能同帧触发，实际耐久感知约等于 100（pipes.yml:23-47）。
7. **Zauker 生产能量符号反转**：常量 `ZaukerProductionEnergy=5000` 为正，但温度更新用 `(T×heatCap - energyReleased)/heatCap`（减法，ZaukerProductionReaction.cs:34）——实际效果是吸热，与"生产消耗能量"的注释一致、与常量的正号相反。
8. **氦的热容比 γ=20**（_Funkystation gases.yml:112）：物理上单原子理想气体 γ≈1.667，20 疑为笔误。
9. **氢的摩尔质量 = 32**（:54）：化学上 H₂ 应为 2，疑抄 O2；氚火/氢火公式因此按摩尔数而非质量守恒。
10. **两个辐射反应无超惰性气体守卫**：PluoxiumRadiationProduction 与 UlnitraniumRadiationProduction（以及 MetalHydrogenReaction）没有其他 Funky 反应都有的 `T>20K && HyperNoblium≥5` 检查——可能是遗漏，也可能是设计（辐射环境本就抑制）。
