# 权限配置器

> 条目ID: `AccessConfigurator` ｜ 来源层: 官方 ｜ 分类: 03-工程部

---

> AI翻译

权限配置器是一种用于指定哪些人员可以使用特定设备的工具。



[权限配置器](../00-实体清单/Objects.md)



可配置的设备包括气闸、保险箱和储物柜，以及权限受限的机器。
注意：为方便起见，气闸的权限也可以通过<span style="color:#a4885c">网络配置器</span>（或多功能工具）配置。

## 在哪里可以找到权限配置器
每个空间站配备最多两个权限配置器。一个在总工程师手中，另一个可以在人事主管那里找到。

## 如何使用权限配置器
使用权限配置器修改设备：
- 首先，对选定的设备使用权限配置器，将它们连接在一起。这会自动打开配置器界面。
- 接下来，将一张 ID 卡插入权限配置器。
- 设置所连接设备的权限要求。可以添加或移除哪些要求，取决于插入的 ID 卡所拥有的权限。
- 任何更改都会<span style="color:#a4885c">立即</span>生效——完成后只需将 ID 卡从权限配置器中取出并关闭界面即可。

## 修改权限的限制
作为安全预防措施，插入的 ID 必须拥有所连接设备当前启用的**所有**权限要求，才能修改它。

例如，一个既允许"科研部"又允许"医疗部"人员访问的设备，只能使用同时拥有<span style="color:#a4885c">这两个</span>部门权限的 ID 卡来修改。
如果插入的 ID 卡没有足够的权限修改设备，权限配置器会警告用户。

没有设置任何权限要求的设备，例如公共访问气闸，可以使用任何有效的空间站 ID 卡修改。

## 修复权限被破解的 ID 卡读卡器
辛迪加特工可能会尝试使用<span style="color:#a4885c">认证干扰器</span>破解权限受限的设备。
这种邪恶的工具会彻底烧毁设备上连接的所有 ID 卡读卡器，使其变成全员可访问。



[认证干扰器](../00-实体清单/Objects.md)



要修复损坏，通常需要部分拆解设备并重新组装。
这会将权限要求重置为默认值，允许你根据需要重新配置设备。

## 修复权限被篡改的气闸
如果气闸的权限要求被篡改，可以通过多种方式修复。

如果你有权限配置器，可以使用<span style="color:#a4885c">螺丝刀</span>卸下气闸的维护面板，然后用权限配置器重新配置气闸的权限要求。
无需部分拆解。

如果你没有权限配置器，仍然可以通过部分拆解气闸、直到拆下门电子元件，然后重新组装来修复它。
这会将气闸重置为班次开始时的默认权限要求。
