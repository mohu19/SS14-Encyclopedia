# 气闸门
气闸门用于控制空间站不同区域的进出权限。


[气闸门](00-实体清单/Structures.md)

  [玻璃气闸门](00-实体清单/Structures.md)

气闸门可以用空手按 <span style="color:yellow">**[keybind="Use"]**</span>、在双手占满时按 <span style="color:yellow">**[keybind="ActivateItemInWorld"]**</span>，或者直接撞上气闸门来打开。

气闸门只会在你持有访问级别正确的 ID 卡时打开。
ID 卡必须拿在手里或放在你的 ID 槽中。
如果你有多张 ID 卡，尝试开门时气闸门会逐一检查它们。
PDA 中的 ID 卡也遵循同样的行为。

打开门所需的访问级别可以用访问配置器修改，或者用万用表对气闸门的门电子元件（需要先拆解）操作来修改。

  [万用表](00-实体清单/Objects.md)

[门控电子元件](00-实体清单/Objects.md)


气闸门会阻断气体流动，因此可以用来在发生[船体破损](57-太空暴露.md)或[火灾](26-火灾.md)时封闭区域。
即使关闭时，气闸门也会在自己的格子上储存气体，所以在气体泄漏期间或之后开门时要小心。

## 门闩与紧急通行
气闸门可以被闩上，防止被打开或被徒手撬开。发生这种情况时，气闸门顶部会亮起红灯。

气闸门也可以设置为紧急通行模式。在这种模式下，任何人都可以打开气闸门，无论访问级别如何。发生这种情况时，气闸门顶部会闪烁黄灯。

## 接线
气闸门的维护面板下有内部接线，可以用螺丝刀打开。
每条线都控制气闸门功能的某个方面。
当你脉冲、剪断或接合某条线时，会对气闸门产生不同的影响。

线旁边的指示灯会显示线的状态：
- 常亮灯表示系统运行正常。
- 闪烁灯表示系统发生故障。它要么不工作，要么行为不符合预期。
- 无灯表示系统未通电。

下面是各条线及其功能列表：

<span style="color:#a4885c">门闩线 (BOLT)</span>
- <span style="color:yellow">脉冲该线</span>：给门上闩或开闩。
- <span style="color:red">剪断该线</span>：给门上闩。
- <span style="color:green">接合该线</span>：无效果。

<span style="color:#a4885c">电源线 (POWR)</span>
- <span style="color:yellow">脉冲该线</span>：短暂切断门的电源。
- <span style="color:red">剪断该线</span>：如果两根电源线都被剪断，则切断门的电源；如果只剪断一根，则会造成短路，电击没有绝缘手套的人。
- <span style="color:green">接合该线</span>：如果两根电源线都被剪断，则恢复门的电源；如果只剪断一根，则停止短路。

<span style="color:#a4885c">日志线 (LOG)</span>
- <span style="color:yellow">脉冲该线</span>：暂时禁用门的日志记录。
- <span style="color:red">剪断该线</span>：禁用门的日志记录。
- <span style="color:green">接合该线</span>：重新启用门的日志记录。

<span style="color:#a4885c">门闩指示灯 (BLIT)</span>
- <span style="color:yellow">脉冲该线</span>：暂时关闭该系统，或将其重新开启。
- <span style="color:red">剪断该线</span>：阻止门闩指示灯亮起——该灯用于显示门是否已上闩。
- <span style="color:green">接合该线</span>：将系统重新开启。

<span style="color:#a4885c">计时器指示灯 (TIMR)</span>
- <span style="color:yellow">脉冲该线</span>：暂时缩短门的计时器。
- <span style="color:red">剪断该线</span>：禁用计时器。门将在安全时立即关闭。
- <span style="color:green">接合该线</span>：重新启用计时器。

<span style="color:#a4885c">安全指示灯 (SAFE)</span>
- <span style="color:yellow">脉冲该线</span>：暂时禁用安全系统。
- <span style="color:red">剪断该线</span>：禁用安全系统。即使存在障碍物，门也会关闭。
- <span style="color:green">接合该线</span>：重新启用安全系统。

<span style="color:#a4885c">AI 访问指示灯 (AIA)</span>
- <span style="color:yellow">脉冲该线</span>：无效果。
- <span style="color:red">剪断该线</span>：禁用 AI 访问权限。AI 将无法再控制这扇门。
- <span style="color:green">接合该线</span>：重新启用 AI 访问权限。
