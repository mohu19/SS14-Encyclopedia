## 1. 概述

超物质（Supermatter）晶体是星光服务器工程部的终极发电核心，也是全站最大的安全隐患。它**不会自己发电**——星光版的核心设计是**"伤害经济学"**：

- 晶体受到的任何伤害都会被放大 3.14 倍，再按比例转化为 4 类"累计能量"：劣化（耐久损伤）、热能、辐射、闪电；
- 其中 82% 的伤害能量以**热能**形式累积，必须由周围气体吸收带走——气体吸收不了的部分会直接转化为**晶体劣化（耐久度下降）**；
- 耐久度归零 → 大爆炸（强度 150）+ 全站蔓延的"级联碎片"。
- 晶体持续受控损伤时，还会把劣化"蒸发"为**氚（Tritium）**与氧——这就是星光超物质的燃料产出机制。

一句话：**超物质引擎 = 用伤害换热量，用热量换氚，控制不住就炸站**。

## 2. 更新节奏（每秒一次）

超物质逻辑挂在自定义基类 `AccUpdateEntitySystem` 上：系统每帧累积 `frameTime`，一旦超过阈值就执行一次批量更新（`AccUpdateEntitySystem.cs:5-13`）。

- 阈值：`Threshold = 1f`（`SupermatterSystem.cs:125`）→ **整套机制每秒执行一次**。
- 每次 `Handle()` 的处理管线（`SupermatterSystem.cs:132-143`）：

```
HandleDamage → HandleGas → HandleRadiation → HandleLighting → HandleDestruction → NotifyCascad → Cascad
```

## 3. 激活条件

- 晶体默认 `Activated = false`（`SupermatterComponent.cs:10`），**不激活就完全不处理**；
- 任何物体与晶体发生碰撞（`EndCollideEvent`）都会把 `Activated` 置为 true（`SupermatterSystem.cs:85`），之后每秒开始完整处理。
- 弹射物（Projectile）与奇点（Singularity）碰撞时直接 return，**不会**伤害晶体或被蒸发（`SupermatterSystem.cs:87-88`），但激活标记仍在碰撞时被置位。

## 4. 触碰与碰撞：焚化

触碰超物质=自杀（除免疫者外）：

- 空手交互（`OnInteract`，`SupermatterSystem.cs:61-81`）：
  - 播放蒸发音效 `/Audio/_Starlight/Effects/supermatter/emitter2.ogg`（`Const.cs:40`）；
  - 对晶体造成 Burn 伤害：`damage = 该实体所有 fixture 密度之和 / 3`（无 Fixtures 时兜底 1）（`SupermatterSystem.cs:73-75`）；
  - 忽略抗性（`TryChangeDamage(..., true)`）；
  - **直接删除触碰者实体** `QueueDel`（`SupermatterSystem.cs:80`）。
- 碰撞（`OnCollide`，`SupermatterSystem.cs:83-105`）：同样公式伤害晶体 + 删除碰撞物。
- 触碰/碰撞者（玩家）会获得成就 `forbidden_candy`（禁果）（`SupermatterSystem.cs:69,94`）。
- 免疫判定见 §13。

## 5. 伤害换算管线（每秒，HandleDamage）

晶体每次受伤后，下一轮 `HandleDamage` 把 Damageable 组件里的伤害**整体放大并清空**（`SupermatterSystem.cs:272-282`）：

| 项目 | 比例 | 公式 | 上限 |
|---|---|---|---|
| 真实伤害 | ×3.14 | `trueDamage = 总伤害 × 3.14`（`Const.cs:13`） | — |
| 劣化能量 AccBreak | 4% | `AccBreak += trueDamage × 0.04`（`Const.cs:9`） | 9999 |
| 热能 AccHeat | 82% | `AccHeat += trueDamage × 0.82`（`Const.cs:8`） | 9999 |
| 闪电能量 AccLighting | 3% | `AccLighting += trueDamage × 0.03`（`Const.cs:10`） | 25 |
| 辐射 AccRadiation | 11% | `AccRadiation += trueDamage × 0.11`（`Const.cs:11`） | 50 |

随后伤害被全部治愈归零（`Damage.Invert()` 负伤害治疗，`SupermatterSystem.cs:276`），下一轮重新从零累计。

> **推论**：每一次打晶体造成的实际耐久代价 = 伤害 × 3.14 × 4% ≈ **伤害 × 0.1256**（前提是热量没被气体带走）。

## 6. 气体互动（每秒，HandleGas）

气体是超物质唯一的"冷却剂"，也是氚的原料来源。`HandleGas`（`SupermatterSystem.cs:205-230`）先做压力/温度伤害（§7、§8），若 `TotalMoles < 1` 直接跳过加热/补偿（`SupermatterSystem.cs:211`）。

### 6.1 气体属性表

每种气体有 3 个属性 `(HeatTransferPerMole 传热系数, HeatModifier 热修正, RadiationStability 辐射稳定性)`（`Const.cs:15-26`），数组下标与气体枚举 `Gas`（`Atmospherics.cs:482-511`）一一对应（Oxygen=0 … Frezon=8）：

| 气体 | 传热系数 (每摩尔) | 热修正 | 辐射稳定性 |
|---|---|---|---|
| 氧 Oxygen | 0.24 | 1.20 | 1.4 |
| 氮 Nitrogen | 0.20 | 1.46 | 1.5 |
| 二氧化碳 CarbonDioxide | 0.12 | 2.21 | 3.5 |
| **等离子体 Plasma** | **0.60** | 0.61 | 1.3 |
| **氚 Tritium** | 0.30 | 0.45 | 1.2 |
| 水蒸气 WaterVapor | 0.14 | 2.31 | 2.5 |
| 氨 Ammonia | 0.16 | 2.11 | 4.4 |
| 一氧化二氮 NitrousOxide | 0.13 | 2.19 | 2.2 |
| **氟利昂 Frezon** | **1.00** | **0.01** | 1.1 |

⚠️ 数组只有 9 项，**BZ、Healium 等 9~21 号气体（Funkystation/星光自定义气体）不提供任何属性**——它们只会稀释摩尔分数（`Atmospherics.cs:493-510`）。

### 6.2 合成公式（每秒）

```csharp
percent            = clamp(该气体摩尔数 / 总摩尔数, 0, 1)          // SupermatterSystem.cs:220
heatTransfer       = Σ(传热系数 × 摩尔数)                          // SupermatterSystem.cs:221
heatModifier       = Σ(热修正 × percent)                           // SupermatterSystem.cs:222
radiationStability = Σ(辐射稳定性 × percent)                       // SupermatterSystem.cs:223
辐射稳定性组件值      = clamp(radiationStability, 1.1, 10)           // SupermatterSystem.cs:226
```

### 6.3 灌热（ProcessHeat，`SupermatterSystem.cs:243-252`）

```
heatDelta = min(AccHeat, heatTransfer)          // 每秒最多把这么多热能灌进气体
AccHeat  -= heatDelta（下限 0，上限 9999）
气体温度  += heatDelta × heatModifier           // 气体被加热
AccBreak += 剩余的 AccHeat                       // 灌不进去的热量 → 直接劣化！
```

**这就是引擎的核心平衡**：

- **冷却能力 = heatTransfer** = 高摩尔数（密度）× 高传热系数。氟利昂每摩尔传热 1.0 最高，等离子体 0.6 次之；
- **气体升温幅度 = heatModifier**：氟利昂热修正仅 0.01（几乎不升温，灌热最多），等离子体 0.61 也偏低，二氧化碳/水蒸气/氨则升温剧烈（2.2~2.3）；
- 若 AccHeat 超过气体吸收能力，**多余热量直接变成耐久劣化** → 越打越热、越热越裂。

### 6.4 蒸发补偿：氚产出（TryCompensateDamage，`SupermatterSystem.cs:232-241`）

```csharp
breakDelta = min(AccBreak, 10)                  // 每秒最多补偿 10 点劣化（Const.cs:33）
AccBreak  -= breakDelta
氚  += breakDelta / 2                            // 1 点劣化 → 0.5 摩尔氚
氧  += breakDelta × 4                            // 1 点劣化 → 4 摩尔氧
```

**每秒最多产出 +5 摩尔氚、+40 摩尔氧**（当 AccBreak ≥ 10）。执行顺序在 ProcessHeat 之后，因此本帧新产生的劣化也能被部分补偿。这就是"受伤的晶体在吐燃料"——受控损伤下的超物质是氚的持续来源。

## 7. 压力机制（每秒，DamageByPressure，`SupermatterSystem.cs:263-270`）

| 项目 | 数值 | 来源 |
|---|---|---|
| 最低安全压力 MinPressure | **33 kPa** | `Const.cs:28` |
| 最高安全压力 MaxPressure | **363.9 kPa** | `Const.cs:29` |
| 伤害公式 | `max(33 − P, P − 363.9) / 100`（越界时） | `SupermatterSystem.cs:268` |
| 伤害类型 | Brute，忽略抗性 | `SupermatterSystem.cs:267-269` |
| 音效 | 晶体开裂 `crystal_crack_1/2.ogg` | `Const.cs:38` |

- 压力处于 33~363.9 kPa 之间：无压力伤害；
- **低压（真空）**：P=0 时每秒 0.33 点 Brute；
- **高压（爆缸）**：P=600 时每秒 2.36 点 Brute——高压伤害是真空的 7 倍；
- 该伤害进入 Damageable 组件，**下一秒**才被 ×3.14 放大换算成累计能量（管线顺序 HandleDamage 在前）。

> 维护推论：真空房和高压房都会慢慢裂晶；SOP 要求在可能失控时把腔室泄压至 0 kPa（见 §14），但按代码 0 kPa 仍会持续造成低压伤害——泄压的意义是防止高压物理爆舱，而不是让晶体"安全"。

## 8. 温度机制（每秒，DamageByTemperature，`SupermatterSystem.cs:254-261`）

| 项目 | 数值 | 来源 |
|---|---|---|
| 温度上限 MaxTemperature | **473.15 K（≈200 °C）** = `T0C(273.15) + 200` | `Const.cs:31`、`Atmospherics.cs:36` |
| 触发条件 | 气体温度 > 473.15 K | `SupermatterSystem.cs:256` |
| 效果 | 施加 Burn 伤害 = `MaxTemperature − 气体温度`（负值） | `SupermatterSystem.cs:259` |
| 音效 | 燃烧 `burning_1/2/3.ogg` | `Const.cs:39` |

⚠️ **重大疑点（按源码实际行为）**：当气体温度超过 473.15 K 时，公式 `MaxTemperature − Temperature` 得到**负数**。本 fork 中负伤害 = 治疗（`DamageableSystem.API.cs:170-175` 的 `HealModifyEvent` 分支）。因此**高温气体实际上在治疗晶体的烧伤伤害**（同时播放燃烧音效），而不是摧毁晶体——效果与直觉相反，疑似反转 bug（若按 `Temperature − MaxTemperature` 才是"高温烧毁"）。治疗会降低总伤害 → 下一轮 trueDamage 变小 → 反而减缓劣化。**文档按代码现状记录，实际效果请以服务器表现为准。**

## 9. 辐射机制（每秒，HandleRadiation，`SupermatterSystem.cs:197-203`）

- 保证 `RadiationSourceComponent` 存在，并把 `Intensity` 设为 AccRadiation（`SupermatterSystem.cs:199-200`）——单位为中心处**每秒拉德（rad/s）**（`RadiationSourceComponent.cs:10-16`），slope 默认 0.5（`RadiationSourceComponent.cs:25`）决定随距离衰减速度；
- `AccRadiation /= 辐射稳定性`（`SupermatterSystem.cs:202`）——每秒衰减，稳定性区间 [1.1, 10]；
- 稳态辐射强度上限 50（§5 表格）。

⚠️ **命名反直觉**："辐射稳定性"数值越大，除得越多、辐射消散越快（如氨 4.4、CO₂ 3.5 让辐射快速衰减；氟利昂 1.1 让辐射久久不散）。

## 10. 闪电机制（每秒，HandleLighting，`SupermatterSystem.cs:190-195`）

- 若 `AccLighting ≠ 0`：调用 `ShootRandomLightnings(晶体, 范围 = AccLighting, 1 道)`（`SupermatterSystem.cs:193`；`LightningSystem.cs:73-99`）；
- 闪电在 `AccLighting` 半径内寻找带 `LightningTarget` 组件的目标，按优先级排序、按各自 `HitProbability` 判定命中，命中则放出一道闪电（`LightningSystem.cs:80-97`）；
- 只要成功放电，AccLighting 清零（`SupermatterSystem.cs:194`）；范围内没有目标或全部落空则保留，继续累积；
- AccLighting 每轮上限 25（§5 表格）。

## 11. 耐久劣化与再生（每秒，HandleDestruction，`SupermatterSystem.cs:182-188`）

```csharp
damageToApply = clamp(AccBreak / 10 − 0.3, −0.3, 0.8556)
Durability    = clamp(Durability − damageToApply, 0, 100)
```

| 项目 | 数值 | 来源 |
|---|---|---|
| 每点劣化对耐久的伤害 | AccBreak / 10 | `SupermatterSystem.cs:184` |
| 自然再生速率 | **0.3 %/秒**（RegenerationPerSecond） | `Const.cs:36` |
| 最大劣化速率 | **0.8556 %/秒** = 100/180 + 0.3（MaxDamagePerSecond） | `Const.cs:35` |
| 耐久区间 | 0 ~ 100，初始 100 | `SupermatterComponent.cs:28` |

- AccBreak 每轮清零，转换为耐久变化；
- 无损伤时晶体每秒回 0.3% 耐久；
- 满速劣化下 100% → 0 最快约 **117 秒（≈2 分钟）**。

⚠️ `Const.cs:35` 注释称"确保至少 3 分钟耗尽"，但按公式 `100 / 0.8556 ≈ 117s`，与注释不符。

## 13. 爆炸与级联（Cascad）

### 13.1 爆炸触发（`SupermatterSystem.cs:145-155`）

耐久 ≤ 0.01 时：

1. 成就 `you_super_matter` 授予所属空间站的**首席工程师**与**大气技术员**岗位玩家（`SupermatterSystem.cs:149-150`）；
2. 爆炸：`QueueExplosion(默认爆炸原型, totalIntensity=150, slope=3, maxTileIntensity=20)`（`SupermatterSystem.cs:152`，参数定义见 `ExplosionSystem.cs:233-250`）——总强度 150、坡度 3、每格最高强度 20；
3. 在晶体坐标启动级联（`SupermatterSystem.cs:153`）；
4. 删除晶体本体（`SupermatterSystem.cs:154`）。

### 13.2 级联蔓延（`SupermatterCascadeSystem.cs`）

- `StartCascade`：以爆炸点为中心生成 **4 条分支**（北/东/南/西），每条寿命 100（`SupermatterCascadeSystem.cs:89-98`）；
- 分支每帧（tick）向当前方向移动 **1 格**，并随机行为（`SupermatterCascadeSystem.cs:39-70`）：

| 随机数 (0-99) | 行为 |
|---|---|
| < 10 | 左转 45° |
| 10 ~ 20 | 右转 45° |
| 20 ~ 25（且分支数 < 10） | 分裂为左右两条分支 |
| 其余 | 直行 |

- 分支遇到**太空/无网格/无 tile** → 该分支移除（`SupermatterCascadeSystem.cs:72-81`）；
- 否则在格子上生成随机一个级联碎片实体 `Cascad1`~`Cascad6`（`SupermatterCascadeSystem.cs:84`、`SupermatterCascadeSystem.cs:19`）；
- 分支总数上限 10；寿命 100 帧 → 单支理论最长蔓延 100 格。

### 13.3 级联碎片实体（`supermatter.yml:49-142`）

- `Cascad1`（其余 2~6 为换贴图的子类）：
  - Damageable：`StructuralInorganic` 容器 + `Glass` 伤害修正（玻璃级）；
  - Destructible：累计 **80 伤害**触发摧毁 + 碎玻璃音效（`supermatter.yml:60-69`）；
  - 贴图 `drawdepth: Walls`（按墙渲染）→ **挡路可破坏障碍**，占 1×1 格。
- 级联效果 = 爆炸后站内地板被"玻璃碎晶"迅速铺满，阻挡通行、需要工程部逐个敲掉。

## 16. 维护要点（机制推导，数值均出自上文）

1. **压力红线 33~363.9 kPa**：真空与高压都在持续裂晶（高压伤害 ≈ 真空 7 倍），压力回路必须可调；
2. **冷却即生存**：腔室内保持**高摩尔数 + 高传热系数**气体（氟利昂每摩尔传热 1.0 最优、等离子体 0.6 次之；氟利昂热修正 0.01 升温最慢，是最佳冷却剂）；气体吸收不了的热量直接转为劣化；
3. **受伤成本**：任何 1 点伤害 → 3.14 × 4% = 0.126 劣化 + 2.57 热能 + 0.35 辐射 + 0.09 闪电；打晶体就是在烧耐久；
4. **辐射与闪电**：受伤越重，辐射（上限 50 rad/s）与 25 格半径随机雷击越猛——需要辐射屏蔽，且受伤时要远离站内 LightningTarget 设备；
5. **受控损伤 = 氚产线**：AccBreak 每秒最多补偿 10 点，转化 +5 氚 / +40 氧——利用晶体"吐燃料"特性可做氚制造（代价是同时向气体灌热）；
6. **警报监听**：耐久每 5% 一跳的工程频道无线电是唯一的远程状态来源；
7. **爆炸即毁灭**：耐久 ≤ 0.01 → 150 强度爆炸 + 4 分支 100 格级联玻璃碎片铺满站内 → 必须留泄压/撤离预案；SOP 要求失控时把腔室泄压至 0 kPa（`engineering-sop-power-generation.xml:10`），且**未经首席工程师许可不得启动超物质晶体**（`engineering-sop-power-generation.xml:8`）；
8. **别碰它**：无免疫装备触碰 = 立即蒸发（成就不归路 `forbidden_candy`）；SOP 亦规定超物质相关操作归大气技术员与首席工程师管。
