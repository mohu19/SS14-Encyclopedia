# Security Officer

[[实体:ToyFigurineSecurity]]

-1.\n

	in
	[[实体:ClothingShoesBootsJack]]


	[[实体:GrenadeFlashBang]]

	[[实体:Handcuffs]]
	or
	[[实体:Zipties]]


- 2.\n
Security Officers should make themselves readily available to the crew, either by patrolling actively or by guarding departments.
- 3.\n
Security Officers are cleared to confine sentenced criminals in the brig for up to **10 minutes**.\n\n
3.1\n
For a sentence to be valid, it must be read aloud to the Warden or Head of Security. If done over radio, an audible confirmation must be received.\n\n
3.2\n
Security officers are responsible for ensuring that any sentences they themselves were involved in are properly documented in the Criminal Records System.
- 4.\n
When practical, Security Officers should patrol in pairs.
