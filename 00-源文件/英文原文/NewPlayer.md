# Welcome to Space Station 14!

  
    [[实体:SignSecureMedRed]]
  
**Gameplay includes;** Kidnapping, Abduction, Murder, Giant Spiders, Mind Control, Pixelated Blood and Gore, Pixelated Nudity

## Introduction
You've just begun your shift aboard a Nanotrasen space station.
You and your fellow crewmates are tasked with working together, surviving, and having fun!

**Make sure to follow all server rules.** You can ask questions or report rule breaks to the <span style="color:#EB2D3A">**admin team**</span> by using the **admin help menu**. (*accessible by pressing *<span style="color:yellow">**[keybind="OpenAHelp"/]**</span>)

More detailed guides about *specific jobs* and *mechanics* can be found [textlink="here." link="SS14"/]

This guide can be reopened at any time using <span style="color:yellow">**[keybind="OpenGuidebook"]**</span>.

## Basic Controls
The following are the controls you'll need for regular gameplay:

- Run using <span style="color:yellow">**[keybind="MoveUp"][keybind="MoveLeft"][keybind="MoveDown"][keybind="MoveRight"]**</span>. Hold down <span style="color:yellow">**[keybind="Walk"]**</span> to walk

- Examine the world around you with <span style="color:yellow">**[keybind="ExamineEntity"]**</span>

- Interact with the world using <span style="color:yellow">**[keybind="Use"]**</span>

- Hovering over an entity and pressing <span style="color:yellow">**[keybind="UseSecondary"]**</span> shows the *context menu*, which contains additional interactions

- Swap hands using <span style="color:yellow">**[keybind="SwapHands"]**</span> and activate the currently held item with <span style="color:yellow">**[keybind="ActivateItemInHand"]**</span>

- Drop held items with <span style="color:yellow">**[keybind="Drop"]**</span> or throw them using <span style="color:yellow">**[keybind="ThrowItemInHand"]**</span>

- Pull and release things with <span style="color:yellow">**[keybind="TryPullObject"]**</span> and <span style="color:yellow">**[keybind="ReleasePulledObject"]**</span>

A more comprehensive list can be found on the [textlink="controls" link="Controls"] page.

## What is SS14?
Space Station 14 is a multiplayer game about paranoia and chaos on a space station and a remake of the cult-classic Space Station 13.

Join dozens of other players on an intricately designed and simulated space station, immersing yourself in roleplay and dealing with threats along the way.

SS14 is an *open-source game* developed by people **just like you!**
It receives <span style="color:lime">daily updates</span> and may at times be <span style="color:#EB2D3A">**unstable.**</span>

*If you want to report bugs or help with development, join the discord and learn how to get started.*
