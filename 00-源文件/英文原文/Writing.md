# Writing

Using a pen, you can write on paper or in books. Nanotrasen provides everyone with a spare pen in their PDA.

## Formatting

You can use the following sigils:

- <span style="color:tan">\[color=color\]\[\/color\]</span> — to change the color of the text
- <span style="color:tan">\[head=n\]\[\/head\]</span> — where *n* is the heading level (1 – 3)
- <span style="color:tan">\[bullet\/\]</span> — to insert a bullet point (useful for lists)
- <span style="color:tan">**\[bold\]\[\/bold\]**</span>, <span style="color:tan">*\[italic\]\[\/italic\]*</span> — for emphasis

You can combine ***bold and italic*** tags, or use the shortcut <span style="color:tan">[bolditalic]\[bolditalic\][/bolditalic]</span>.

Color supports either hexadecimal or most HTML color names. For example:

- <span style="color:#ff0000">\[color=#ff0000\]\[\/color\]</span>
- <span style="color:red">\[color=red\]\[\/color\]</span>
