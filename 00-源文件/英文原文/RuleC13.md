# Core Rule 13 - Use realistic character names, and do not use names of famous people
  - No names of people or characters from the real world
  - No titles/honorifics
  - Must follow all other rules (no slurs/sexual names/etc)
  - Usernames, objects, random characters, very "low effort" names, "meta" names, or otherwise implausible names cannot be used as names. See examples below.
  - Admin rulings on IC names are final and disputes should be done through the forums, not by refusing to comply with an admin

  Clowns and mimes are exempt from the prohibition on titles/honorifics, and have loosened restrictions on low effort and implausible names.

  ## Clarification on "Meta" Names
  Meta names are ones which attempt to take advantage of some game mechanic or game design choice. "Urist McHands" is a meta name because it is the default name used for admin spawned humans. "Operator Whiskey" is a meta name because it follows the naming pattern of nuclear operatives. This rule is not intended to prevent things like nuclear operatives using a fake ID with names that appear to be nuclear operative names if they decide that they want to do that.

  ## Conventions and Examples
  <span style="color:#994444">Bad</span> cannot be used by any species. <span style="color:#449944">Acceptable</span> names can be used by any species.

  Humans typically use the Firstname Lastname convention.
  - <span style="color:#449944">Acceptable:</span> Tom Fisher
  - <span style="color:#449944">Acceptable:</span> Spacey Chapman
  - <span style="color:#994444">Bad:</span> Dr. Tom Fisher
  - <span style="color:#994444">Bad:</span> Walter White
  - <span style="color:#994444">Bad:</span> George Washington
  - <span style="color:#994444">Bad:</span> Joe Biden
  - <span style="color:#994444">Bad:</span> Ben Dover
  - <span style="color:#994444">Bad:</span> Mike Hunt

  Dwarfs typically use the human convention in a viking theme.
  - <span style="color:#449944">Acceptable:</span> Ingrid Firebreath
  - <span style="color:#449944">Acceptable:</span> Erik Lightningclaw

  Lizards typically use the Verb-article-Noun convention.
  - <span style="color:#449944">Acceptable:</span> Cleans-the-Airlocks
  - <span style="color:#994444">Bad:</span> Bans-the-Admins

  Slimes typically have names that are onomatopoeia. A last name is optional.
  - <span style="color:#449944">Acceptable:</span> Foolp Suub
  - <span style="color:#449944">Acceptable:</span> Foolp
  - <span style="color:#994444">Bad:</span> Slime

  Diona typically have calm, nature themed, Noun of Noun style names.
  - <span style="color:#449944">Acceptable:</span> Petal of Tranquility
  - <span style="color:#449944">Acceptable:</span> Garden of Relaxation
  - <span style="color:#994444">Bad:</span> Tree but Alive

  Mothmen typically use latin sounding names, or light themed names.
  - <span style="color:#449944">Acceptable:</span> Socrates Temnora
  - <span style="color:#449944">Acceptable:</span> Sierra Lightseeker
  - <span style="color:#449944">Acceptable:</span> James Nightflitter

  Arachnids typically use latin sounding names.
  - <span style="color:#449944">Acceptable:</span> Argyroneta Reticulatus
  - <span style="color:#449944">Acceptable:</span> Loxosceles Domesticus
  - <span style="color:#994444">Bad:</span> Spider-Man

  Vox typically use a single name made of random syllables, often with repeating patterns.
  Names should not be excessively long or be so repetitive/convoluted as to be unreadable.

  - <span style="color:#449944">Acceptable:</span> Hirixashahre
  - <span style="color:#449944">Acceptable:</span> Xapikrikrik
  - <span style="color:#994444">Bad:</span> Chipikirchitchitchitbecretretrer
  - <span style="color:#994444">Bad:</span> Trololol

  Usernames, objects, random characters, very "low effort" names, "meta" names, or otherwise implausible names are not permitted.
  - <span style="color:#994444">Bad:</span> XxRobustxX
  - <span style="color:#994444">Bad:</span> SDpksSodjdfk
  - <span style="color:#994444">Bad:</span> Lkdsoisgoieun
  - <span style="color:#994444">Bad:</span> F4ith H3arth
  - <span style="color:#994444">Bad:</span> Greytide
  - <span style="color:#994444">Bad:</span> Assistant
  - <span style="color:#994444">Bad:</span> Urist McHands
  - <span style="color:#994444">Bad:</span> Admin
  - <span style="color:#994444">Bad:</span> Game-Master
  - <span style="color:#994444">Bad:</span> Joe Mamma
  - <span style="color:#994444">Bad:</span> Middle-Aged Man
  - <span style="color:#994444">Bad:</span> Operative Whiskey
