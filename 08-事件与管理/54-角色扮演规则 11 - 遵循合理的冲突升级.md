# 角色扮演规则 11 - 遵循合理的冲突升级

> 条目ID: `RuleR11` ｜ 来源层: 官方 ｜ 分类: 08-事件与管理

---

> AI翻译

敌对角色完全豁免冲突升级规则。与敌对角色发生冲突的非敌对角色不豁免。冲突升级通常应遵循步骤或冲突类型模式，类似于：
- 言语
- 无害
- 非致命
- 致命
- 永久致命

所有新的冲突都应从第一步开始。如果没有冲突另一方的某些升级行为，玩家不应跨级升级冲突。玩家可以跳过步骤以匹配对方所处的升级水平，但除此之外几乎不应跳过步骤。尝试缓和冲突的玩家，如果对方无视缓和尝试继续升级，那么他们在升级时会被给予更多宽容。你不必尝试缓和冲突，但一个观察了你整个回合或多个回合的人，不应觉得你的目标总体上是升级冲突。

冲突或升级可以是间接的。当某人偷走别人的 ID 卡时，盗窃是冲突的直接部分，但如果受害者因为没有了 ID 卡而无法开门、被困住，这也被视为冲突和升级的一部分。不要随机偷别人的 ID 卡。

升级不必针对特定玩家才会使其卷入冲突。试图摧毁空间站的核弹队被视为与空间站上所有船员处于永久致命的冲突级别。杀死空间站宠物的人与所有船员都产生了某种程度的冲突。杀死厨师正在照料的老鼠的人，与那位厨师产生了某种程度的冲突。

如果你基于错误或不合理的假设升级冲突，你将被视为违反此规则。

冲突几乎不应该达到"永久致命"阶段。只有对方将冲突带到这个阶段，或者同一冲突在本局中多次升级到致命阶段时，冲突才应达到这个阶段。

如果冲突中的一方进入耐伤状态或死亡，责任方应带他们去接受治疗或交给安保部门。就这场冲突而言，这应被视为挽救某人免于死亡，并应缓和冲突。如果冲突以这种方式得到缓和，双方都需要重新升级到致命级别，冲突才能回到那个阶段。如果冲突没有以这种方式缓和，那么只有击败对方的一方需要重新升级，冲突才能回到致命阶段。

如果有必要逮捕某人，安保部门可以立即升级到非致命武力。

使用或挥舞辛迪加物品的人通常可以被推定具有致命意图。对于有致命意图的人，通常可以立即以致命级别应对升级，一个显著的例外是你有安全拘留他们的工具。

参见[涉及动物的冲突升级](52-R11-1.md)。

## 豁免

冲突升级规则不对非玩家执行，但如果玩家没有意识到某个角色或动物由另一名玩家控制，他们仍要为自己的违规行为负责。断线离开的角色仍被视为玩家。被检查时显示紫色文字"无法恢复"（recovery is impossible）的角色被视为非玩家。

## MRP 修正案

冲突升级规则即使对非玩家也执行。

## 示例场景

这些示例假设你不是敌对角色。

可接受：
- 一名玩家开始打你，所以你开始还手，直到他们停手。如果他们进入耐伤状态，你停止攻击并带他们去安保部门或接受医疗。
- 你取笑一个小丑，小丑朝你扔了一个派并偷走了你的鞋子。你滑倒小丑并偷走他们的面具。
- 你是一名安保官，让某人停下以便询问他们。他们逃跑，于是你用眩晕枪击晕并铐住他们。
- 你是一名安保官，看到有人穿着辛迪加硬质太空服，于是把他们射成耐伤状态，铐住他们，然后带他们去安保部门。
- 你是一名船员，看到核弹队成员，于是杀死他们。
- 未经授权的人进入空间站的高风险区域，比如军械库或大气部门，于是你攻击他们直到他们离开。
- 为了自己的利益给别人造成轻微的不便。
- 作为敌对角色，杀死挡了你路的人。
- 作为敌对角色，杀死没有给你想要东西的人。
- 一名厨师和一名酒保通过适当的升级达到了致命级别的冲突。厨师把酒保打成耐伤状态，但没有带他们去医疗区或安保部门。酒保下次遇到厨师时立刻试图把厨师打成耐伤状态。
- 一名厨师和一名酒保通过适当的升级达到了致命级别的冲突。厨师把酒保打成耐伤状态，但没有带他们去医疗区或安保部门。厨师下次见到酒保时侮辱了他们。
- 一名货运技术员接到了运送大脑的货运悬赏。在收到医疗部送来的一具检查时显示紫色文字"任何恢复都是不可能的"（Any recovery is impossible.）的尸体后，货运技术员永久销毁了这具尸体以取出大脑。

禁止：
- 一名玩家开始打你，于是你把他们碎尸。
- 一个小丑朝你扔了一个派并偷走了你的鞋子，于是你用螺丝刀把他们捅成耐伤状态。
- 你是一名安保官，让某人停下以便询问他们。他们逃跑，于是你用警棍把他们打成耐伤状态。
- 一个其实有权进入的人——你却毫无道理地或草率地认为他无权——进入了空间站的高风险区域，比如军械库或大气部门，于是你攻击他们直到他们离开。
- 未经授权的人进入空间站的低风险区域，比如货运部，你在没有任何其他升级的情况下就开始攻击他们。
- 因为他们是安保部门，就整局滑倒他们。
- 因为人事主管没有给你想要的东西，就用墙把人事主管堵在办公室里。
- 因为某人本局早些时候打了你，就藏起他们的尸体。
- 频繁进入酒吧打碎他们的杯子或家具来骚扰酒吧或酒保。
- 随机找人打架。
- 作为非敌对角色，从断线离开的玩家那里偷 ID 卡。
- 一名厨师和一名酒保通过适当的升级达到了致命级别的冲突。厨师把酒保打成耐伤状态，但没有带他们去医疗区或安保部门。厨师下次遇到酒保时立刻试图把酒保打成耐伤状态。
- 一名厨师和一名酒保通过适当的升级达到了致命级别的冲突。厨师把酒保打成耐伤状态，并带他们去了医疗区或安保部门。酒保下次遇到厨师时立刻试图把厨师打成耐伤状态。
- 一名货运技术员接到了运送大脑的货运悬赏。在走廊里发现一具尸体后——这具尸体被检查时没有"任何恢复都是不可能的"（Any recovery is impossible.）的紫色文字——货运技术员永久销毁了这具尸体以取出大脑。
