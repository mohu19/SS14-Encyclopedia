# 发电

> AI翻译


[S.U.P.E.R.P.A.C.M.A.N. 型便携式发电机](00-实体清单/Structures.md)


1. 非大气部门的工程人员必须先建立反物质引擎（AME）和/或接入太阳能网络，然后才能转向其他电源。未能做到这一点将被视为立即解雇的理由。

2. 未经总工程师明确许可，不得启动特斯拉球、奇点与超级物质芯。

3. 超级物质芯的腔室必须配备紧急泄压系统，以便在可能发生脱层时将腔室内压力降至 0 kpa。

4. 大气人员可在输配与废气管线都完成后启动 TEG 和/或超级物质芯。
