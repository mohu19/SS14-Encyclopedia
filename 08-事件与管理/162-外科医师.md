# 外科医师


[医师手办](00-实体清单/Objects.md)


1. 外科医师直接向首席医疗官汇报。

2. 患者进行任何择期手术前，必须填写并签署 *手术同意书*。该表格必须由首席医疗官盖章。

3. 手术时，外科医师应尽可能佩戴口罩、无菌手套并穿着手术服。

4. 手术室必须保持干净整洁，以保障患者卫生。

5. 外科医师可从已被判定无法救回的死亡患者身上摘取器官和肢体。

6. 活体患者在手术期间必须给予镇静剂，除非患者另有要求。任何此类要求都必须记录在其 *手术同意书* 上。
