# 核心规则 C13 - 使用现实的角色名，不得使用名人姓名

> 条目ID: `RuleC13` ｜ 来源层: 官方 ｜ 分类: 08-事件与管理

---

> AI翻译

- 不得使用现实世界人物或角色的名字
- 不得使用头衔/敬称
- 必须遵守所有其他规则（不得使用侮辱性称呼/色情名字等）
- 用户名、物品名、随机字符、非常「敷衍」的名字、「meta」名字或其他不合理的名字不能用作角色名。参见下文示例。
- 管理员对入戏名字的裁决是最终决定，争议应通过论坛解决，而不是拒绝服从管理员

小丑和哑剧演员不受头衔/敬称禁令的限制，并且在敷衍和不合理的名字方面有更宽松的限制。

## 关于「Meta」名字的说明
Meta 名字是指试图利用某种游戏机制或游戏设计选择的名称。「Urist McHands」是一个 meta 名字，因为它是管理员生成人类时使用的默认名字。「Operator Whiskey」是一个 meta 名字，因为它遵循核弹队的命名模式。本规则无意阻止核弹队成员使用带有看似核弹队名字的假身份证之类的行为，如果他们决定要这么做的话。

## 命名惯例与示例
<span style="color:#994444">不可</span>的名字任何物种都不能使用。<span style="color:#449944">可接受</span>的名字任何物种都可以使用。

人类通常采用「名 + 姓」的命名惯例。
- <span style="color:#449944">可接受：</span> Tom Fisher
- <span style="color:#449944">可接受：</span> Spacey Chapman
- <span style="color:#994444">不可：</span> Dr. Tom Fisher
- <span style="color:#994444">不可：</span> Walter White
- <span style="color:#994444">不可：</span> George Washington
- <span style="color:#994444">不可：</span> Joe Biden
- <span style="color:#994444">不可：</span> Ben Dover
- <span style="color:#994444">不可：</span> Mike Hunt

矮人通常采用维京风格的类人命名惯例。
- <span style="color:#449944">可接受：</span> Ingrid Firebreath
- <span style="color:#449944">可接受：</span> Erik Lightningclaw

蜥蜴人通常采用「动词-冠词-名词」的命名惯例。
- <span style="color:#449944">可接受：</span> Cleans-the-Airlocks
- <span style="color:#994444">不可：</span> Bans-the-Admins

拉斯比（Slimes）的名字通常是拟声词。姓是可选的。
- <span style="color:#449944">可接受：</span> Foolp Suub
- <span style="color:#449944">可接受：</span> Foolp
- <span style="color:#994444">不可：</span> Slime

狄奥娜通常采用宁静、自然主题的「名词 of 名词」风格名字。
- <span style="color:#449944">可接受：</span> Petal of Tranquility
- <span style="color:#449944">可接受：</span> Garden of Relaxation
- <span style="color:#994444">不可：</span> Tree but Alive

蛾人通常使用听起来像拉丁语的名字，或与光有关的主题名字。
- <span style="color:#449944">可接受：</span> Socrates Temnora
- <span style="color:#449944">可接受：</span> Sierra Lightseeker
- <span style="color:#449944">可接受：</span> James Nightflitter

蛛人通常使用听起来像拉丁语的名字。
- <span style="color:#449944">可接受：</span> Argyroneta Reticulatus
- <span style="color:#449944">可接受：</span> Loxosceles Domesticus
- <span style="color:#994444">不可：</span> Spider-Man

沃克斯通常使用由随机音节组成的单名，常带有重复模式。
名字不应过长，也不应重复或复杂到难以阅读。

- <span style="color:#449944">可接受：</span> Hirixashahre
- <span style="color:#449944">可接受：</span> Xapikrikrik
- <span style="color:#994444">不可：</span> Chipikirchitchitchitbecretretrer
- <span style="color:#994444">不可：</span> Trololol

用户名、物品名、随机字符、非常「敷衍」的名字、「meta」名字或其他不合理的名字是不允许的。
- <span style="color:#994444">不可：</span> XxRobustxX
- <span style="color:#994444">不可：</span> SDpksSodjdfk
- <span style="color:#994444">不可：</span> Lkdsoisgoieun
- <span style="color:#994444">不可：</span> F4ith H3arth
- <span style="color:#994444">不可：</span> Greytide
- <span style="color:#994444">不可：</span> Assistant
- <span style="color:#994444">不可：</span> Urist McHands
- <span style="color:#994444">不可：</span> Admin
- <span style="color:#994444">不可：</span> Game-Master
- <span style="color:#994444">不可：</span> Joe Mamma
- <span style="color:#994444">不可：</span> Middle-Aged Man
- <span style="color:#994444">不可：</span> Operative Whiskey
