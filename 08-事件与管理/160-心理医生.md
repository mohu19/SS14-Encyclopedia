# 心理医生


[医师手办](../00-实体清单/Objects.md)


1. 心理医生直接向首席医疗官汇报。

2. 心理医生有权对任何自愿的船员进行全面的心理测量评估。

3. 对不情愿的船员的检查，只有在获得首席医疗官以及以下其中一人的书面批准后才能进行：安保主管、治安官、船长。
- 1. 这也适用于心理医生开具的任何药物。

4. 检查结果可导致以下处理措施，且需经船长或船员所属部门主管签字确认：
- 1. 如果患者的心理状态使其无法履行职责，可将其从现职降职。
- 2. 对被发现极度暴力的人员，可开具 Pax 或其他类似药物的处方。
- 3. 对被判定构成危险的囚犯或船员加强监视。
- 4. 对表现良好、道德品格有所转变的囚犯减轻刑罚。

5. 心理医生可随时要求与囚犯会面，以评估其心理状态。
